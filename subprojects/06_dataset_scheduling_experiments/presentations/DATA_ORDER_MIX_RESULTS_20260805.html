Order changes what the model remembers

Five trajectories consumed the same 80.730B-token stream once, with identical HPLT, GlossAPI/non-HPLT, foreign replay, Old-Greek replay, packing, optimizer, and WSD-10 schedule. Only the temporal order of the two Modern-Greek pools changed.

D0 Mixed is the observed all-round leader: it passes the source-retention safety screen, leads the predeclared endpoint hierarchy, and has lower clean GreekMMLU choice NLL than every ordered arm under paired question bootstrap. It is not yet a statistically resolved winner because the frozen source-loss outputs lack document-cluster rows.

Small endpoint gaps, placed on a zero-centered scale

The complete trajectories above show when forgetting occurs. This secondary view shows full endpoint BPB minus D0 for each replay panel so the much smaller between-arm differences remain visible.

Ordering influences replay less than it influences Greek source loss, but not uniformly.
