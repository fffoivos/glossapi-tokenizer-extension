# 06 · initialization — Mini tokenizer overlay and tied Token Distillation

> **In one line:** built the one 0.5B starting checkpoint that all five data-order arms shared — a Mini-compatible 148,992-token vocabulary plus a tied-embedding Token-Distillation initialization that had to beat plain FVT before it could be used.
> **Period:** 2026-08-01 → 2026-08-02. **Status:** completed; one artifact frozen and consumed unchanged by D0–D4.
> **Came from / led to:** the tokenizer audit in [`../evidence/tokenizer_compatibility_audit_20260801.json`](../evidence/tokenizer_compatibility_audit_20260801.json) → this → the packed corpus in [`../dataset/`](../dataset/) and every arm in [`../training/`](../training/).

## Why this existed

Two problems had to be solved before any arm could start. First, the production Greek tokenizer could not be attached to Mini verbatim: the two share the full 269,443-entry base merge prefix, but **14 base token IDs mean different things** and the front-end metadata differs, so copying it would silently re-label pretrained embedding rows. Second, Mini has `tie_word_embeddings=true` — one shared `[148992, 1024]` table — so none of the 8B project's untied layer-11 TD evidence transfers, and the Token Distillation paper reports a specific large-norm generation-collapse failure mode on exactly this kind of model. The rationale and the full gate table are in [`../INITIALIZATION_AND_TRAINING_DECISIONS.md`](../INITIALIZATION_AND_TRAINING_DECISIONS.md) §§1–2.

## History

1. **Overlay, not copy.** [`build_mini_tokenizer_overlay.py`](build_mini_tokenizer_overlay.py) keeps Mini IDs `0..131071` and its `tokenizer.json` front end, then appends the exact production tokens and dependency-ordered merges at `131072..148991`. Vocabulary 148,992 = 256 × 582, no alignment-only rows. The upstream `pad_token_id=3` / `[INST]` inconsistency is resolved by declaring the *existing* `<pad>` at ID 10 as pad — no ID, merge or embedding meaning changes. [`tokenizer_geometry.py`](tokenizer_geometry.py) holds the exact BPE geometry helpers; [`prepare_mini_overlay.py`](../dataset/prepare_mini_overlay.py) materializes it on CSCS.
2. **Fresh counts were mandatory.** Because the front end is Mini's, the earlier 63.823B production-tokenizer token count became planning evidence only; [`build_token_byte_lengths.py`](build_token_byte_lengths.py) and the pool receipts recount from scratch.
3. **FVT baseline first.** [`build_tied_retok_init.py`](build_tied_retok_init.py) initializes every new row from the mean of its decomposition under the pinned Mini vocabulary. The decomposition comes from the appended merge DAG, not from decoding one ByteLevel token in isolation; [`normalize_td_coverage_geometry.py`](normalize_td_coverage_geometry.py) converts the reusable subproject-03 coverage prepass to that exact geometry.
4. **A four-cell TD pilot on a shared 1,024-token set.** Target layer 7 vs the last layer, crossed with MSE-on-hiddens vs MSE + `CE-auto-weighted` next-token loss ([`select_mini_td_pilot_tokens.py`](select_mini_td_pilot_tokens.py), [`train_tied_token_distillation.py`](train_tied_token_distillation.py), [`select_tied_td_pilot.py`](select_tied_td_pilot.py)). AdamW, LR `1e-4`, one epoch, batch 16, 25 accepted contexts per token; `learn_output_with_ce` stays false because a second output-only pass would double-handle the same tied matrix.
5. **Fail-closed selection.** The winning cell had to have the lowest three-slice macro BPB **and** not regress against untouched tied FVT; if every cell regressed, the campaign would not launch. [`verify_tied_initialization.py`](verify_tied_initialization.py) adds the independent structural, norm (`max new-row norm / p99.9 base-row norm <= 4`, a rejection gate, not clipping), teacher-forced argmax and greedy generation-collapse checks.
6. **Full range, then freeze.** The selected recipe ran once over IDs `131072..148991` ([`write_full_added_token_ids.py`](write_full_added_token_ids.py), [`build_td_assets_from_packed_training.py`](build_td_assets_from_packed_training.py)); tokens with fewer than 25 valid contexts keep their deterministic FVT row rather than being trained on duplicated evidence, with a ≥90% TD-trained floor. [`finalize_mini_td_initialization.py`](finalize_mini_td_initialization.py) froze the artifact; [`torch_to_torchdist.py`](torch_to_torchdist.py) and [`finalize_td_megatron_conversion.py`](finalize_td_megatron_conversion.py) verified the HF → Megatron `torch_dist` → HF round trip; [`freeze_base_mini_model.py`](freeze_base_mini_model.py) and [`freeze_td_runtime.py`](freeze_td_runtime.py) pin the base checkpoint and the external runtime.

## Outcome

- One frozen tied-TD initialization hash, used identically by D0–D4 — the header of [`../INITIALIZATION_AND_TRAINING_DECISIONS.md`](../INITIALIZATION_AND_TRAINING_DECISIONS.md) records the tokenizer, tied-TD and fresh-count gates as passed.
- The pad-metadata correction (ID 10, not ID 3) is a standing constraint for any TD batching or evaluation code that touches Mini.
- The per-cell pilot numbers (which layer/loss cell won, and by how much) are not stored in this repository; they live in the CSCS selection receipts referenced by the finalizer. Treat the recipe choice as receipt-backed but not locally auditable.
