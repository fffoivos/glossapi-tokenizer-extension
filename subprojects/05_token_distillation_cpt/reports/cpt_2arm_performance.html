3 · Held-out language-modeling quality

Three 0.5 B-token held-out Greek sets, excluded from training (zero leakage), measured every 25 steps. Per-token loss is not comparable across tokenizers — so the fair comparison is bits-per-byte (right), where the text bytes are identical and the token counts cancel.

In bits/byte the two arms are essentially tied on language modeling (TD slightly better on in-domain OpenArchives, vanilla marginally better on PhD theses). So the Greek tokenizer + Token Distillation buys the downstream Greek gain without any compression cost.

4 · Tokenizer efficiency (the practical win)

The Greek-extended tokenizer represents the same Greek text in far fewer tokens — directly lowering inference cost and extending effective context.

Across the held-out sets the TD tokenizer uses 1583 M tokens where the base tokenizer needs 2309 M — a 31% reduction (HPLT −38%, OpenArchives −30%, PhD −26%). At equal 13.5 B-token budget the TD arm therefore also sees more Greek text.

Efficiency milestone. Multi-node training was blocked for a day by a Slingshot/CXI NO_SPACE error; root cause was the trainer's hardcoded NCCL_NET_FORCE_FLUSH=1 (a tiny per-receive flush that the 1.18-dev OFI plugin rejects). Removing it unblocked full 64-GPU CXI/RDMA training and beat the Socket/HSN fallback by ~12%/iter — turning a projected ~4.7-day-per-arm run into ~8 h.

6 · Methodology & caveats

  • Equal token budget (13.5 B each), not equal epochs: TD ≈ 1.0 epoch of its 13.5 B-token binary; vanilla ≈ 0.69 epoch of its 19.5 B-token binary (same documents, same compute) — the standard tokenizer-comparison protocol.
  • Per-token loss ≠ cross-arm comparable; cross-arm claims use bits/byte (§3) or downstream accuracy (§1–2).
  • Data: 10 B unseen Greek (70% HPLT + 30% OpenArchives) + 3.5 B replay (multilingual + code + math + Greek replay), GreekMMLU-decontaminated and PII-anonymized. The HPLT→OpenArchives ordering was prepared but did not take effect — Megatron's dataloader shuffle was left on — so both arms trained on shuffled data (does not affect the arm comparison).
  • bits/byte uses held-out JSONL byte counts (~1% JSON overhead, identical for both arms → cross-arm comparison exact; absolute value ~1% high).
  • Hyperparameters: peak LR 5.5e-5, WSD (20% 1-sqrt cooldown), AdEMAMix (β 0.9/0.995/0.999, α 4), Goldfish k=h=50, RoPE θ=500k/seq 4096, TP2/PP1/DP32, bf16. TD arm initialized with Token Distillation (Dobler 2025) at layer 11 (E by MSE-on-hiddens, U by CE).
