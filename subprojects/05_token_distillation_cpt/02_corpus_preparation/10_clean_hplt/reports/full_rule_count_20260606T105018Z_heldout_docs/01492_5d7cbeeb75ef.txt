Πώς να ρυθμίσετε το απόρρητο του Facebook ώστε να είναι ασφαλές
Ως εκ τούτου, αναφέρεται από το Techradar, εδώ είναι οι ρυθμίσεις απορρήτου και ασφάλειας που πρέπει να αλλάξετε στο Facebook. Το θέμα είναι να αποφευχθούν παραβιάσεις της ιδιωτικής ζωής.
ΔΕΙΤΕ ΑΡΘΡΑ1. Συνδεθείτε με ασφάλεια
Θα ξεκινήσουμε από την αρχή. Έτσι, εάν είστε Σύνδεση σε έναν λογαριασμό Facebook από έναν κοινόχρηστο υπολογιστή υπολογιστή (οικογενειακός ή δημόσιος υπολογιστής), καταργήστε την επιλογή "Διατήρηση σύνδεσης".
Λοιπόν, αν προκύψει το ερώτημα "Θυμηθείτε το πρόγραμμα περιήγησης" Όπως η παραπάνω φωτογραφία, είναι καλύτερο να επιλέξετε "Μην αποθηκεύετε". Ωστόσο, εάν την ενεργοποιήσετε, θα λάβετε μια ειδοποίηση όταν κάποιος χρησιμοποιεί τον υπολογιστή σας για να συνδεθεί στον λογαριασμό σας στο Facebook.
2. Ανοίξτε τις Ρυθμίσεις απορρήτου
Το Facebook έχει κάνει πολλές νέες αλλαγές για να κάνει τις ρυθμίσεις απορρήτου πιο προσβάσιμες. Για να το δείτε, κάντε κλικ στο κουμπί λουκέτου επάνω δεξιά.
Από εκεί, θα δείτε πολλές επιλογές απορρήτου. Σε αυτά περιλαμβάνονται ο "έλεγχος απορρήτου", "ποιος μπορεί να δει τις αναρτήσεις μου;", "Ποιος μπορεί να επικοινωνήσει μαζί μου;" και "πώς μπορώ να κάνω τους ανθρώπους να σταματήσουν να με παρενοχλούν;".
Ακόμα δεν είναι αρκετό; Μπορείτε επίσης να δείτε άλλες ρυθμίσεις ή να επισκεφθείτε τα βασικά στοιχεία απορρήτου.
3. Έλεγχοι απορρήτου
Από τις ρυθμίσεις απορρήτου, επιλέξτε τώρα την πρώτη, δηλαδή "Έλεγχος απορρήτου". Υπάρχουν 3 βήματα για να βεβαιωθείτε ότι μοιράζεστε περιεχόμενο με το σωστό άτομο.
Πρώτον, όποτε κάνετε μια κατάσταση, μπορείτε να ελέγξετε ποιος μπορεί να τη δει, οπότε απλώς προσαρμόστε την. Υπάρχει ένα "δημόσιο" για όλους στο Facebook ή για να το βλέπουν, "φίλοι" και άλλες ειδικές ρυθμίσεις.
Δεύτερον, θα δείτε μια λίστα εφαρμογών συνδεδεμένων στο Facebook σας. Προσαρμόστε ή καταργήστε τα δικαιώματα εάν δεν έχετε χρησιμοποιήσει ποτέ την εφαρμογή.
Τρίτον, οι πληροφορίες του προφίλ σας. Αυτό είναι πολύ σημαντικό. Ξεκινώντας από τηλέφωνο, email, ημερομηνία γέννησης και πόλη προέλευσης. Παρακαλώ ρυθμίστε το, θέλετε να εμφανίζεται ή όχι.
4. Ποιος μπορεί να δει τις δημοσιεύσεις μου;
Σε αυτήν την επιλογή, εκτός από το να μπορείτε να ορίσετε ποιος βλέπει την κατάστασή σας Θέση, μπορείτε επίσης να ελέγξετε ποιος μπορεί να δει ή να βρει τα πράγματα που δημοσιεύετε, καθώς και ποιος σας επισημαίνει με το "Αρχείο καταγραφής δραστηριοτήτων"
Ω ναι, μπορείτε επίσης να δείτε τι βλέπουν άλλοι άνθρωποι στη χρονολογία σας και πώς θα μοιάζει το προφίλ σας όταν προβάλλονται από συγκεκριμένα άτομα.
5. Ποιος μπορεί να επικοινωνήσει μαζί μου;
Επιπλέον, μπορείτε επίσης να ορίσετε ποιος μπορεί να στείλει φίλους σε εσάς. Υπάρχουν 2 επιλογές, δηλαδή όλοι ή φίλοι φίλων. Για να μην στέλνουν απλώς αιτήματα φίλων, επιλέξτε "φίλος φίλων".
6. Πώς μπορείς να κάνεις τους ανθρώπους να σταματήσουν να με εντοπίζουν;
Υπάρχουν άνθρωποι που δεν ξέρετε ότι σας ενοχλούν; Μπορείτε να αποκλείσετε αυτό το άτομο ή να το φιλέψετε και να το εμποδίσετε να επικοινωνήσουν ξανά μαζί σας.
Απλώς πληκτρολογήστε το όνομα ή το email σας. Λοιπόν, μπορείτε επίσης να δείτε όλους τους αποκλεισμένους χρήστες.
7. Ρυθμίσεις και εργαλεία απορρήτου
Για πιο ολοκληρωμένες ρυθμίσεις, κάντε κλικ στην επιλογή "Προβολή περισσότερων ρυθμίσεων. Μπορείτε να προβάλετε περισσότερες ρυθμίσεις και εργαλεία απορρήτου.
Θα δείτε πρόσθετες ρυθμίσεις, όπως ποιος μπορεί να σας αναζητήσει χρησιμοποιώντας τη διεύθυνση ηλεκτρονικού ταχυδρομείου, τον αριθμό τηλεφώνου σας ή αν θέλετε οι μηχανές αναζήτησης εκτός του Facebook να συνδέονται με το προφίλ σας.
8. Ρυθμίσεις χρονολογίας και σήμανσης
Σύμφωνα με το απόρρητο, υπάρχουν ρυθμίσεις τεχνολογίας και ετικετών. Από εδώ, μπορείτε να ελέγξετε ποιος μπορείετικέτες εσείς. Μπορείτε επίσης να ενεργοποιήσετε τον έλεγχο των αναρτήσεων που σας επισημαίνουν, προτού τελικά εμφανιστούν στο χρονολόγιό σας.
Φυσικά, δεν θέλετε να επισημανθείτε με κάτι ασαφές, σωστά; Λοιπόν, υπάρχουν ακόμα μερικές ρυθμίσεις για να ασφαλίσετε και να διαχειριστείτε τη χρονολογία σας.
9. Ενεργοποίηση ειδοποιήσεων και έγκρισης εισόδου
Το επόμενο βήμα για την ασφάλεια του λογαριασμού σας στο Facebook είναι να ενεργοποιήσετε τις ειδοποιήσεις σύνδεσης. Το κόλπο, ανοίξτε το Ρυθμίσεις λογαριασμού >Ασφάλεια και επιλέξτε "Ειδοποιήσεις σύνδεσης".
Με αυτό, θα λάβετε μια προειδοποίηση σύνδεσης όταν κάποιος συνδεθεί στον λογαριασμό σας. Είτε από τη συσκευή είτε πρόγραμμα περιήγησης που δεν αναγνωρίζεται.
10. Χρησιμοποιήστε έλεγχο ταυτότητας δύο βημάτων
Αυτό θεωρείται σημαντικό και πρέπει να ενεργοποιηθεί. Ρυθμίστε τη σύνδεση στο Facebook χρησιμοποιώντας τον αριθμό τηλεφώνου σας ως πρόσθετη ασφάλεια. Φυσικά, για να αποτρέψετε άλλα άτομα να εισέλθουν κρυφά στον λογαριασμό σας.
Με αυτό, παρόλο που έχουν όνομα χρήστη και ο κωδικός πρόσβασής μας στο Facebook, δεν θα μπορεί να εισαχθεί, επειδή απαιτείται ένας επιπλέον κωδικός για την αποστολή στον αριθμό τηλεφώνου.
Αυτοί είναι 10 τρόποι για να ρυθμίσετε το απόρρητο και την ασφάλεια του Facebook που πρέπει να ελέγξετε ακόμη και αν πρέπει να το αλλάξετε. Ο στόχος είναι να μην χρησιμοποιούνται τα δεδομένα σας από άλλα άτομα. Προστατεύετε πάντα το απόρρητό σας. Καλή τύχη!
