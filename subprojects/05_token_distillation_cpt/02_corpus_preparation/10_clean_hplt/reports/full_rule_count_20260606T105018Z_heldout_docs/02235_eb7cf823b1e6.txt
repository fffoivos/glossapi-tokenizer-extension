Το ταξίδι, όπως φυσικά το καθετί που κάνουμε στη ζωή μας, απαιτεί την απαραίτητη προετοιμασία, έτσι ώστε να αποφύγετε τη στιγμή που θα πείτε «Ωχ, ξέχασα...», ή ακόμη και να μην ταξιδέψετε καθόλου. Ταξιδιωτικά έγγραφα Βεβαιωθείτε ότι έχετε μαζί σας τα ταξιδιωτικά σας έγγραφα (διαβατήριο, ταυτότητα ή βίζα), αφού προηγουμένως τσεκάρετε ότι είναι σε ισχύ και δεν έχουν λήξει. Καλό θα ήταν να έχετε και αντίγραφα των εγγράφων σε περίπτωση απώλειάς τους. Πριν το αεροδρόμιο Φροντίστε να κάνετε Web Check-in, έτσι ώστε να αποφύγετε την ταλαιπωρία στο αεροδρόμιο, αλλά και ένα πιθανό πρόστιμο (ανάλογα με την πολιτική που εφαρμόζει η εκάστοτε εταιρεία). Παράλληλα, καλό θα ήταν να τσεκάρετε εάν η πτήση σας έχει κάποια καθυστέρηση, ή εάν η ώρα αναχώρησής σας έχει αλλάξει. Δεν θέλουμε ούτε να καθόμαστε στο αεροδρόμιο με τις ώρες και φυσικά ούτε να χάσουμε την πτήση μας. Διαβάστε επίσης: Οδηγός ταξιδιού: Τι μπορεί να μπει στη βαλίτσα μας και τι απαγορεύεται Περί βαλίτσας ο λόγος Αφού έχουμε φορτώσει τη βαλίτσα μας με όλα τα προσωπικά μας αντικείμενα, το πρώτο που θα πρέπει να κάνουμε είναι να την ζυγίσουμε, για να βεβαιωθούμε ότι δεν έχουμε ξεπεράσει το επιτρεπόμενο όριο. Πάντα όμως, θα πρέπει να λαμβάνουμε υπόψη ότι υπάρχει και η επιστροφή και καλό θα ήταν να αφήναμε ένα περιθώριο γι αυτά που θα ψωνίσουμε. Ακολούθως, σιγουρευτείτε ότι έχετε τοποθετήσει καρτελάκι με τα προσωπικά σας στοιχεία στη βαλίτσα (όνομα, τηλέφωνο και διεύθυνση), έτσι ώστε σε περίπτωση απώλειας οι αρχές του αεροδρομίου να επικοινωνήσουν μαζί σας. Τέλος, μεριμνήστε να έχετε μαζί σας κλειδαριές. Γενικά Φυσικά, αυτές που κάνουν το ταξίδι μας ακόμη ευκολότερο είναι οι λεπτομέρειες. Οπότε, πριν πάτε ελέγξτε το είδος της πρίζας που διαθέτει κάθε χώρα, έτσι ώστε να προμηθευτείτε και τους ανάλογους αντάπτορες (μπορείτε εδώ να δείτε τι ισχύει σε κάθε χώρα). Ακόμη, μία ματιά στην πρόγνωση του καιρού για τις επόμενες ημέρες θα ήταν χρήσιμη. Πολιτική Δημοσίευσης Σχολίων Οι ιδιοκτήτες της ιστοσελίδας www.politis.com.cy διατηρούν το δικαίωμα να αφαιρούν σχόλια αναγνωστών, δυσφημιστικού και/ή υβριστικού περιεχομένου, ή/και σχόλια που μπορούν να εκληφθεί ότι υποκινούν το μίσος/τον ρατσισμό ή που παραβιάζουν οποιαδήποτε άλλη νομοθεσία. Οι συντάκτες των σχολίων αυτών ευθύνονται προσωπικά για την δημοσίευση τους. Αν κάποιος αναγνώστης/συντάκτης σχολίου, το οποίο αφαιρείται, θεωρεί ότι έχει στοιχεία που αποδεικνύουν το αληθές του περιεχομένου του, μπορεί να τα αποστείλει στην διεύθυνση της ιστοσελίδας για να διερευνηθούν. Προτρέπουμε τους αναγνώστες μας να κάνουν report / flag σχόλια που πιστεύουν ότι παραβιάζουν τους πιο πάνω κανόνες. Σχόλια που περιέχουν URL / links σε οποιαδήποτε σελίδα, δεν δημοσιεύονται αυτόματα.
