Η Αφροδίτη σε τετράγωνο με τον Ποσειδώνα: Πως θα επηρεάσει το ζώδιό σου;
Στις 16 Ιουνίου η Αφροδίτη από τις 29° 52’ των Διδύμων θα βρεθεί σε όψη τετραγώνου με τον Ποσειδώνα που βρίσκεται στους Ιχθύες. Με την όψη αυτή εύκολα μπορεί να βγουν στη επιφάνεια ανασφάλειες και φοβίες μας. Παράλληλα, και δεδομένου ότι βασική μας ανάγκη θα είναι το να είμαστε αρεστοί, να μας επαινούν και να μας αγαπούν, δεν θα μας είναι εύκολο να πούμε όχι. Θα είμαστε περισσότερο διατεθειμένοι να κάνουμε σημαντικές υποχωρήσεις και να υιοθετήσουμε συμπεριφορές που δεν "κουμπώνουν" στον πραγματικό χαρακτήρα μας με αποτέλεσμα στο τέλος να νιώσουμε εσωτερική καταπίεση, άγχος, θλίψη και γενικά να γεμίσουμε δυσάρεστα συναισθήματα.
Μεγάλες προσδοκίες!
Η αλήθεια είναι ότι η όψη αυτή είναι κάπως έντονη, κυρίως γιατί θα μας φέρει μπροστά σε άβολες καταστάσεις και αλήθειες που θα πρέπει να αντιμετωπίσουμε. Το να σταματήσουμε να κλείνουμε τα μάτια και τα αυτιά μας στο όποιο πρόβλημα έχουμε μπροστά μας είναι υψίστης σημασίας γιατί, με τον τρόπο αυτό, το πρόβλημα, όχι μόνο δε θα εξαφανιστεί, αλλά, επιπλέον, όταν βρεθούμε πρόσωπο με πρόσωπο με αυτό, δεν θα είμαστε προετοιμασμένοι να το αντιμετωπίσουμε.
Σε ό,τι αφορά τις αισθηματικές σχέσεις μας, η Αφροδίτη από το ζώδιο των Διδύμων θα μας ωθήσει να αφεθούμε στο φλερτ, την ανεμελιά, το ερωτικό παιχνίδι και τους πειραματισμούς και γενικά να αντιμετωπίσουμε πιο ανάλαφρα και αέρινα τον έρωτα. Η σχεδόν εφηβική διάθεσή μας στο να γνωρίσουμε, να απολαύσουμε και να ενθουσιαστούμε, θα μας κάνει κάπως άστατους και επιφανειακούς ενώ η προσωπική μας ευχαρίστηση θα είναι αυτό που θα μας κινητοποιεί. Ακόμα και αν επιθυμούμε μια πιο εγκεφαλική σύνδεση με το ταίρι ή το αντικείμενο του πόθου μας, η συμπεριφορά μας θα είναι αμφιθυμική και με έντονες διακυμάνσεις, κάτι που θα μπερδεύει, θα αποπροσανατολίζει και θα δημιουργεί ένα αίσθημα ανεπάρκειας. Επίσης, θα υπάρξουν διλήμματα, μπερδέματα, διαψεύσεις και γενικά δυσκολίες στις σχέσεις.
Με την όψη αυτή επίσης, θα χρειαστεί να καταλάβουμε ότι, με το να εξιδανικεύουμε ανθρώπους και καταστάσεις, με το να λειτουργούμε με γνώμονα μόνο το συναίσθημα αφήνοντας στην άκρη τη λογική και με το να αγνοούμε τα προφανή ελαττώματα ή συμπεριφορές των άλλων που "μυρίζουν" εγωπάθεια, αλαζονεία και αδιαφορία για τις δικές μας ανάγκες και αισθήματα, κάνουμε κακό στον ίδιο μας τον εαυτό και λειτουργούμε σαν τροχοπέδη της ίδιας μας την εξέλιξης.
Αναφορικά με τα επαγγελματικά μας, θα χρειαστεί να δείξουμε αυτοσυγκράτηση και αυτοπειθαρχία καθώς θα έχουμε την τάση να τα "φορτώσουμε όλα στον κόκορα" και να αναζητήσουμε τρόπους να ξεφύγουμε από την πραγματικότητα, αφήνοντας πίσω ευθύνες και υποχρεώσεις. Σε ό,τι αφορά τα οικονομικά μας και επειδή η βασική μας ανάγκη θα είναι αυτή του να περάσουμε όμορφα, ανέμελα και να διασκεδάσουμε, εύκολα θα βάλουμε το χέρι πιο βαθιά στη τσέπη προκειμένου να ικανοποιήσουμε τις ανάγκες μας, ακόμα και αν αυτό σημαίνει ότι θα "τραβήξουμε" από χρήματα που είχαμε για να καλύψουμε άλλες πιο βασικές ανάγκες. Επίσης, επειδή γενικά θα είμαστε επιρρεπείς σε λάθη, καλό θα ήταν να αποφύγουμε επενδύσεις και οικονομικά ανοίγματα.
Πως θα σε επηρεάσει η Αφροδίτη σε τετράγωνο με τον Ποσειδώνα;
Αυτή η όψη θα διαρκέσει διαρκέσει +/- 4 μέρες και θα επηρεάσει τους εκπροσώπους των ζωδίων του μεταβλητού σταυρού, δηλαδή: Διδύμους, Παρθένους, Τοξότες, και Ιχθύες γεννημένους στο τέλος του 3ου δεκαήμερου των ζωδίων αυτών καθώς και όσους έχουν ωροσκόπο, μεσουράνημα ή προσωπικούς πλανήτες, δηλαδή: Σελήνη, Ερμή, Αφροδίτη και Άρη στα ζώδια αυτά ή στο δεκαήμερο αυτό.
Πάμε να δούμε πως θα επηρεαστεί κάθε ζώδιο ξεχωριστά:
ΚΡΙΟΣ
Μη δώσετε ελαφρά τη καρδία υποσχέσεις που δεν είστε σίγουροι ότι θα μπορέσετε να κρατήσετε και μην ανακατευτείτε με κουτσομπολιά και μεταφορά ειδήσεων γιατί θα εκτεθείτε. Πλησιάστε με περισσότερη συμπάθεια τους άλλους και θα βγείτε κερδισμένοι.
ΤΑΥΡΟΣ
Να είστε προσεκτικοί γιατί θα είστε επιρρεπείς, τόσο σε οικονομικές, όσο και σε συναισθηματικές εξαπατήσεις. Προστατέψτε τον εαυτό σας από περιπέτειες και, σε ό,τι αφορά το χρήμα, προσπαθήστε να είστε λογικοί και πρακτικοί και όχι πεισματάρηδες και αμετακίνητοι.
ΔΙΔΥΜΟΙ
Σε ό,τι αφορά επαγγελματικές συμφωνίες και οικονομικές διαπραγματεύσεις, θα πρέπει να είστε πολύ προσεκτικοί και ευέλικτοι γιατί δεν έχουν όλοι τη δική σας καλή διάθεση και ηθική. Καλό είναι να μην έχετε μεγάλες προσδοκίες. Κινηθείτε αργά και σταθερά.
ΚΑΡΚΙΝΟΣ
Κάποιες πληροφορίες που θα φτάσουν στα αυτιά σας σχετικά με τις, όχι και τόσο, έντιμες κινήσεις συνεργάτη ή προσώπου από το άμεσα κοινωνικό περιβάλλον σας, θα σας προβληματίσουν και θα σας αναγκάσουν να λάβετε τα μέτρα σας πριν η κατάσταση ξεφύγει του ελέγχου.
ΛΕΩΝ
Θα πρέπει να είστε προσεκτικοί με τους ανθρώπους που απαρτίζουν την "αυλή σας" γιατί θα υπάρξουν άνθρωποι που μπορεί να σας εκφράζουν το θαυμασμό και την εκτίμηση τους, ο απώτερος σκοπός τους όμως θα είναι η συναισθηματική ή οικονομική εκμετάλλευσή σας.
ΠΑΡΘΕΝΟΣ
Οι υπερβολικές προσδοκίες αναφορικά με μια επαγγελματική συνεργασία ή με μια προσωπική σας σχέση σε συνδυασμό με την ανάγκη σας όλα να πάνε κατ' ευχήν, εύκολα θα σας οδηγήσουν σε λάθος συμπεράσματα και αποφάσεις. Λειτουργήστε με βάση τη λογική.
ΖΥΓΟΣ
Μην αφήσετε να σας απογοητεύσουν τυχόν καθυστερήσεις ή αναβολές στα επαγγελματικά σχέδιά σας και να σκέφτεστε ότι όλα θα γίνουν στον καταλληλότερο για εσάς χρόνο. Ορισμένοι θα αναλάβετε κάποια επιπλέον καθήκοντα που θα χρειαστούν προσεκτικούς χειρισμούς.
ΣΚΟΡΠΙΟΣ
Θα χρειαστεί να παλέψετε λίγο παραπάνω για να τακτοποιήσετε ένα θέμα σχετικό με κληρονομιές, δάνεια ή χρήματα που διαχειρίζεστε με τρίτους. Αισθηματικά, προσέξτε την τάση σας να αφήνετε να σας παρασύρουν σε άγνωστα νερά το πάθος και οι ερωτικές φαντασιώσεις.
ΤΟΞΟΤΗΣ
Είστε γεμάτοι ενθουσιασμό και όρεξη για παντός τύπου περιπέτειες. Ωστόσο, ενδέχεται να σας προσγειώσουν κάπως απότομα υποχρεώσεις και ευθύνες σχετικές, είτε με το ταίρι σας, είτε με τους οικείους ή την κατοικία σας. Κατεβάσετε ταχύτητες και περιμένετε για καλύτερες συνθήκες.
ΑΙΓΟΚΕΡΩΣ
Η ανάγκη σας για διαφάνεια και ειλικρίνεια μπορεί να σας κάνει κάπως άκομψους στον τρόπο που επικοινωνείτε και έτσι να πείτε κάπως "χοντροκομμένες αλήθειες" που θα πληγώσουν τους άλλους. Το τακτ και οι καλοί τρόποι θα σας φανούν χρήσιμοι και στο επαγγελματικό περιβάλλον.
ΥΔΡΟΧΟΟΣ
Η ανάγκη σας να νιώσετε ανάλαφροι, χαρούμενοι και να κάνετε εντύπωση, ειδικά στο άτομο που έχετε ερωτικά στοχοποιήσει, θα σας οδηγήσουν σε έξοδα και λάθος κινήσεις. Σε ό,τι αφορά νέες γνωριμίες, να είστε προσεκτικοί γιατί μπορεί να σας "πουλήσουν φύκια για μεταξωτές κορδέλες".
ΙΧΘΥΕΣ
Θα χρειαστεί να αντιμετωπίσετε κάποια θέματα σχετικά με την κατοικία ή τα μέλη της οικογένειάς σας. Προσπαθήστε να κρατήσετε χαμηλούς τόνους. Μην πάρετε βιαστικές αποφάσεις που μπορεί να τις μετανιώσετε και μην πείτε πράγματα που δεν θα μπορείτε να πάρετε πίσω.
