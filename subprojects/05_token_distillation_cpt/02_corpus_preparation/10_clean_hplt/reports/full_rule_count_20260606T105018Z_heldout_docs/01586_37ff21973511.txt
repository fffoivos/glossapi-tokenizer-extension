H BitTorrent, ανακοίνωσε μια νέα δωρεάν και ανοιχτή προς το κοινό υπηρεσία μεταφοράς όπως αυτή του Dropbox που θα επιτρέπει το file transfer αρχείων έως 1 TB! Η υπηρεσία ονομάζεται SoShare και έχει σαν στόχο τους επαγγελματίες της μουσικής, φωτογραφίας, σχεδίου που διαχειρίζονται μεγάλα αρχεία και έχουν ως τώρα πρόβλημα στην αποστολή τους σε τρίτους χρήστες λόγω περιορισμών στον μέγεθος του αρχείου που μπορεί να μεταφερθεί με τις έως τώρα file sharing και mail υπηρεσίες όπως π.χ. το We Transer... Η λειτουργία του SoShare βασίζεται στο πρωτόκολλο BitTorrent με cloud caching, ώστε τα αρχεία να είναι διαθέσιμα ακόμα και αν ο αποστολέας είναι offline, ενώ το όριο του 1TB αφορά το σύνολο της μεταφερόμενης πληροφορίας, είτε πρόκειται για ένα αρχείο είτε για πολλά μαζί. Τα αντίγραφα των αρχείων θα αποθηκεύονται για 30 ημέρες στους servers του BitTorrent ενώ θα υπάρχει δυνατότητα να διαγράφονται νωρίτερα αν το επιθυμεί ο χρήστης. Για να μπορέσετε να χρησιμοποιήσετε την υπηρεσία απαιτείται η εγκατάσταση ενός browser plugin που συνεργάζεται με Chrome, Firefox, Safari και Internet Explorer, ενώ για τα shared αρχεία δεν θα χρειάζεται εγγραφή.
