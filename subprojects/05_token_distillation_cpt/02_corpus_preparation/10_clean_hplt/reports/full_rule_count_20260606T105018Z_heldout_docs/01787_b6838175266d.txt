«Νέα εβδομάδα με νέες προβλέψεις» 20/04/2015 – 26/04/2015 Το τετράγωνο Ερμή-Δία, μας θέλει προσεχτικούς στα λόγια και στις πράξεις μας! Τι λένε όμως αναλυτικά οι προβλέψεις για αυτήν την εβδομάδα; Κριός Κριέ μου, σημαντικές σταθερές και δεδομένα της ζωής σου θέλεις να ανατραπούν κι εσύ αναζητάς τρόπο να το επιτυχείς. Αρχικά καλό θα ήταν να βεβαιωθείς ότι όντως μπούχτισες απ’ το τώρα που ζεις και είσαι έτοιμος για τη μεγάλη ανατροπή. Ταύρος Ταύρε μου, κάπου υπεραναλύεις τα δεδομένα της εβδομάδας και τείνεις να χάσεις την πραγματική διάσταση του προβλήματος. Αμφιταλαντεύεσαι αν μπορείς, κι αν αντέχεις να ανατρέψεις τη ρουτίνα σου ή αν για ακόμη μια φορά θα προτιμήσεις την πεπατημένη οδό. Δίδυμος Διδυμάκι μου, η άνοιξη μπήκε για τα καλά κι έφτασε η ώρα να ασχοληθείς λίγο πιο σοβαρά με το φαίνεσθαι. Μην εγκαταλείψεις την εικόνα σου, είναι μια καλή ευκαιρία να πάρεις τα πάνω σου και να ανεβάσεις λίγο τη διάθεσή σου. Καρκίνος Καρκίνε μου, κάπου δυσκολεύεσαι να εντάξεις νέα δεδομένα στη ζωή σου, καθότι λίγο συντηρητικός. Το να μένεις προσκολλημένος στα ίδια και τα ίδια δε σε βοηθά να πας μπροστά. Λέων Λέοντα μου, η θεατρικότητα, το λέγειν και η εξυπνάδα σου μπορούν να σε γλιτώσουν από πολλές κακοτοπιές. Βασίσου στο χιούμορ σου και σε όλα τα παραπάνω για να ξεπεράσεις τις επαγγελματικές τρικλοποδιές που προκύπτουν. Παρθένος Παρθενάκι μου, το κομπόδεμα σου έχει αρχίσει να εξαντλείται επικίνδυνα. Η προτεραιοτήτων θα σε ανανεώσει αλλά και θα σε βοηθήσει να βάλεις μια τάξη στο οικονομικό χάος. Ζυγός Ζυγέ μου, το ξέρω πως αυτή τη βδομάδα θα προτιμούσες να μη μιλάς, να μην αποφασίζεις και να μην δίνεις απαντήσεις. Λογικό μου ακούγεται, καθώς άπειρα δεδομένα και διλήμματα μπαίνουν στο μιξεράκι του μυαλού σου και μύλος η κατάσταση. Σκορπιός Σκορπιέ μου, μια νέα είσοδος είναι ικανή να προκαλέσει πανικό και να ταρακουνήσει συθέμελα τη βαρετή καθημερινότητά σου. Τα σκηνικό της ζωής σου ανατρέπεται κι αυτό δεν είναι απαραίτητα κακό. Τοξότης Τοξοτάκι μου, η εβδομάδα σε μπερδεύει κι αυτό γιατί μπαίνεις στο τριπάκι να αποκωδικοποιήσεις και να επεξεργαστείς διπλά και τριπλά τις πληροφορίες που φτάνουν στα αυτιά σου. Καλό θα ήταν να μη δώσεις όμως και μεγάλη βάση. Αιγόκερως Αιγοκεράκι μου, οφείλεις να κλείσεις οριστικά τα ανοιχτά μέτωπα της ζωής σου που σε κρατούν στάσιμο και δε σε αφήνουν να εξελιχθείς και να προχωρήσεις. Έφτασε η ώρα για τη μεγάλη ανατροπή. Υδροχόος Υδροχόε μου, το πλανητικό σκηνικό επιβάλλει να βάλεις σε τάξη την λίγο άτακτη και φευγάτη σκέψη σου. Έτσι λοιπόν, δέσε τη ζώνη σου και προσγειώσου σε μια πραγματικότητα που σε θέλει σοβαρό και μετρημένο.Φρόντισε λοιπόν, να βοηθήσεις τον εαυτό σου να εξελιχθεί και να ξεπεράσει τις φοβίες του. Ιχθύς Ψαράκι μου, φρόντισε την εβδομάδα αυτή να καλύψεις με αρκετές δόσεις ρεαλισμού, τη ρομαντική ψυχή σου. Εγώ σε προειδοποιώ καθώς το πλανητικό σκηνικό έρχεται να σε προσγειώσει ανώμαλα και να σου υπενθυμίσει πώς δύσκολος καιρός για πρίγκιπες.
