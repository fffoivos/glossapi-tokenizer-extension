Η κριτική σκέψη, λοιπόν, είναι η ικανότητα του να μπορείς να σκέφτεσαι και να μπορείς να κρίνεις. Η ικανότητα αυτή δεν είναι κάτι το έμφυτο στους ανθρώπους αλλά είναι μία ικανότητα που καλλιεργείται μέσα από καταστάσεις που παρακινούν το παιδί να σκέφτεται, να κρίνει, καλλιεργώντας παράλληλα την φαντασία και τη δημιουργικότητα του. Η ικανότητα αυτή είναι τόσο σημαντική γιατί αποτελεί τον ακρογωνιαίο λίθο για κάθε μορφή μάθησης, για την ωριμότητα του ανθρώπου ως προς τη σωστή λήψη των αποφάσεων και την εξεύρεση λύσεων σε προβλήματα. Αυτό μπορεί να γίνει, οργανώνοντας τις δραστηριότητες που έχει, σκεφτόμενο τον χρόνο που θα χρειαστεί για κάθε τι. Αρχικά, το παιδί μπορεί να δυσκολευτεί στην οργάνωση αλλά θα αρχίσει σταδιακά να αυτορυθμίζεται.
