Το Google Chrome σύντομα θα σας προειδοποιεί όταν χρησιμοποιείτε αδύναμους κωδικούς πρόσβασης. Η υπηρεσία είναι αυτή την στιγμή στο canary και αναμένεται να έρθει στην σταθερή έκδοση. Η ασφάλεια των διαδικτυακών λογαριασμών σας εξαρτάται σε μεγάλο βαθμό από το πόσο ισχυροί είναι οι κωδικοί πρόσβασής σας και, αν είναι αυτοί είναι πολύ εύκολοι, οι hackers θα μπορούσαν να εισβάλουν στους λογαριασμού σας. Για να βεβαιωθεί το Chrome ότι οι χρήστες του δεν χρησιμοποιούν αδύναμους κωδικούς πρόσβασης, πρόσθεσε μία νέα λειτουργία ελέγχου ασφάλειας που θα σας ειδοποιεί εάν ο αποθηκευμένος κωδικός είναι αδύναμος. Η νέα δυνατότητα έρχεται να συμπληρώσει την ήδη υπάρχουσα όπου σας ειδοποιεί αν κάποιος αποθηκευμένος κωδικό σας εντοπιστεί σε βάσης δεδομένων με παραβιασμένους κωδικούς. Η Google θα εντοπίζει και θα επισημαίνει αυτόματα τους αδύναμους κωδικούς πρόσβασης κατά τη διενέργεια ελέγχου ασφαλείας, όπως φαίνεται παρακάτω. Η νέα λειτουργία ελέγχου ασφάλειας του Chrome δεν είναι ακόμη διαθέσιμη στο σταθερό κανάλι, αλλά μπορείτε να την ενεργοποιήσετε στο Chrome Canary ακολουθώντας αυτά τα βήματα:
- Στο Browser Chrome Canary ανοίξτε την καρτέλα Chrome://flags
- Κάντε αναζήτηση της λέξης “weak” (αδύναμο) και ενεργοποιήστε τις σημαίες: “Safety check for weak passwords” (Έλεγχος ασφάλειας για αδύναμους κωδικούς πρόσβασης) και “Passwords weakness check” (Έλεγχος αδυναμίας κωδικών πρόσβασης).
3. Όταν σας ζητηθεί να επανεκκινήσετε το πρόγραμμα περιήγησης, κάντε το.
Για να ελέγξετε τους αδύναμους κωδικούς πρόσβασής σας χρησιμοποιώντας έλεγχο ασφαλείας, απλώς μεταβείτε στις Ρυθμίσεις > Έλεγχος ασφάλειας > Έλεγχος τώρα για να πραγματοποιήσετε έλεγχο ασφαλείας των κωδικών πρόσβασής σας.
Μόλις κάνετε κλικ, η Google θα σαρώσει αυτόματα τους αποθηκευμένους κωδικούς πρόσβασης και θα επισημάνει τους πιο αδύναμους. Μπορείτε να κάνετε κλικ στο κουμπί “Review” (Έλεγχος) για να κάνετε αλλαγές στον αποθηκευμένο κωδικό πρόσβασης.
