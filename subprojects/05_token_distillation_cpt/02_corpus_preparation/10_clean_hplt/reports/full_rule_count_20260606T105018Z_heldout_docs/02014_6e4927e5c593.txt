Βασικά βήματα για να ξεκινήσετε μια ομάδα FIRST Tech Challenge: 1] Επιστρατεύστε προπονητές και μέντορες. 2] Φτιάξτε την Ομάδα σας 3] Υλικό Σεζον και Κανόνες παιχνιδιού 4] Fundraising / Χρηματοδότηση / Marketing / Outreach 5] Μελέτη υλικού για τους μέντορες και τις ομάδες 6] Κατασκευή Ρομπότ 7] Προγραμματισμός Ρομπότ 8] Βραβεία και Προετοιμασία για τον Διαγωνισμό 9] Υλικό Κοινότητας FTC Τελευταία ενημέρωση 21/11/2024 Οι ομάδες FIRST Tech Challenge σχεδιάζουν και κατασκευάζουν ένα ρομπότ χρησιμοποιώντας ένα κιτ επαναχρησιμοποιήσιμων εξαρτημάτων και ανταγωνίζονται μέσα σε ένα κοινό σύνολο κανόνων παιχνιδιού για να παίξουν ένα συναρπαστικό παιχνίδι πεδίου και να ολοκληρώσουν τη συγκεκριμένη πρόκληση της σεζόν. Το παιχνίδι ρομπότ αλλάζει κάθε σεζόν και είναι πάντα εκπληκτικό! Οι μαθητές και οι μέντορες της ομάδας ενθαρρύνονται να φέρουν τις δεξιότητες που έχουν ήδη, όπως προγραμματισμό, ηλεκτρονικά, μεταλλουργία, γραφιστική, δημιουργία ιστοσελίδων, δημόσια ομιλία, βιντεοσκόπηση και πολλά άλλα. Το FIRST Tech Challenge καλωσορίζει κάθε μαθητή, με ή χωρίς ειδικές δεξιότητες. Επιστρατεύστε προπονητές και μέντορες Κάθε ομάδα χρειάζεται δύο ή περισσότερους ενήλικες προπονητές/μέντορες που είναι πρόθυμοι και έχουν κίνητρο να προπονήσουν την ομάδα κατά τη διάρκεια της σεζόν κατασκευής και ανταγωνισμού και μετά. Άλλοι ενήλικες μπορούν να προσφέρουν εθελοντικά βοήθεια για τη διοίκηση, τη συγκέντρωση χρημάτων, την προσέγγιση της κοινότητας, τις τεχνικές δεξιότητες και άλλες εργασίες. Οι περισσότερες ομάδες συναντιούνται μία έως δύο φορές την εβδομάδα κατά τη διάρκεια της σεζόν κατασκευής και ανταγωνισμού, η οποία συνήθως διαρκεί από τον Σεπτέμβριο έως τον Μάρτιο. Φτιάξτε την ομάδα σας Βρείτε και προσκαλέστε μερικούς μαθητές (το πολύ 15) που θέλουν να είναι μέρος μιας ομάδας ρομποτικής. Φροντίστε να τονίσετε ότι δεν απαιτούνται τεχνικές δεξιότητες, μόνο ενθουσιασμός και διάθεση για μάθηση. Στρατολογήστε κάθε είδους ταλέντα, όχι μόνο μηχανικά και ηλεκτρικά. Ομάδες του FTC μπορούν να ψάξουν για ταλέντα και σε άλλους διαγωνισμούς όπως ο FIRST LEGO League Challenge. Υλικό Σεζόν και Κανόνες παιχνιδιού Fundraising / Χρηματοδότηση / Marketing / Outreach Η ομάδα σας θα πρέπει να δημιουργήσει έναν προϋπολογισμό και να χρηματοδοτήσει τους στόχους της. Επικοινωνήστε με τοπικές επιχειρήσεις για να σας χορηγήσουν. Ετοιμάστε το πλάνο σας και παρουσιάστε το σε υποψήφιους χορηγούς. Το λογισμικό FIRST Tech Challenge απαιτεί η ελάχιστη έκδοση που χρησιμοποιείται για την εκτέλεση του προγράμματος να είναι η 9.0. Αυτό περιλαμβάνει τις εφαρμογές και τα εργαλεία ανάπτυξης λογισμικού. Για πολλές ομάδες, οι αγώνες είναι η ανταμοιβή για όλη τη σκληρή δουλειά τους όλη τη σεζόν. Ωστόσο, το FIRST Tech Challenge είναι κάτι περισσότερο από έναν διαγωνισμό ρομποτικής. Εκτός από τους αγώνες ρομπότ, οι ομάδες μπορούν επίσης να κερδίσουν τα βραβεία των κριτών. Η επιλογή των νικητών είναι δύσκολη υπόθεση και οι κριτές παίρνουν την ευθύνη πολύ σοβαρά. Τα βραβεία των κριτών αντιπροσωπεύουν έναν θετικό τρόπο αναγνώρισης ομάδων που ενσωματώνουν σημαντικές αξίες όπως ο Gracious Professionalism™, η ομαδική εργασία, η δημιουργικότητα, η καινοτομία και η αξία της διαδικασίας μηχανικού σχεδιασμού. Παρακάτω είναι μια λίστα με τα βραβεία, συγκεκριμένα κριτήρια περιγράφονται στο Game Manual Part 1.
