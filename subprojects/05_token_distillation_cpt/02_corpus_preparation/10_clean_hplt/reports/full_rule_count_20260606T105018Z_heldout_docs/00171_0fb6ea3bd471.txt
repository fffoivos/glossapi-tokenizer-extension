Πώς να διορθώσετε τη δημόσια σελίδα σύνδεσης WiFi που δεν εμφανίζεται στα Windows 10; Μία από τις χαρές που επισκέπτεστε ένα καφέ ή ένα εμπορικό κέντρο είναι η δημόσια πρόσβαση Wi-Fi που απολαμβάνουμε. Τι γίνεται όμως αν μετά τη σύνδεση στο δίκτυο, η σελίδα σύνδεσης αρνείται να εμφανιστεί; Έτσι, δεν μπορείτε να περιηγηθείτε στο Διαδίκτυο. Τι μπορείτε να κάνετε όταν βρεθείτε σε μια τέτοια επιδιόρθωση; Συνεχίστε να διαβάζετε για να μάθετε πώς να εμφανίζεται μια δημόσια σελίδα σύνδεσης Wi-Fi. Πώς να αναγκάσετε να ανοίξει μια σελίδα σύνδεσης δημόσιου δικτύου Wi-Fi Τα δωρεάν και επί πληρωμή δημόσια δίκτυα Wi-Fi έχουν ένα κοινό κοινό, και είναι η δεσμευμένη πύλη. Πρόκειται για μια ιστοσελίδα που συναντάτε προτού σας δοθεί πρόσβαση στο Διαδίκτυο. Συχνά απαιτεί την εισαγωγή ενός προκαθορισμένου αναγνωριστικού χρήστη και κωδικού πρόσβασης ή την αποδοχή ορισμένων όρων χρήσης. Φανταστείτε την ταλαιπωρία όταν είστε μακριά από το σπίτι. Έχετε μια διάσκεψη για να προετοιμαστείτε, αλλά δεν μπορείτε να συνδεθείτε σε ένα Wi-Fi ξενοδοχείου, επειδή η δεσμευμένη πύλη αρνείται να εμφανιστεί στο πρόγραμμα περιήγησης της συσκευής σας Windows 10. Δεν μπορείτε να δείτε μια δημόσια σελίδα σύνδεσης Wi-Fi; Δοκιμάστε αυτές τις λύσεις:
- Επανεκκινήστε τον υπολογιστή σας
- Χρησιμοποιήστε διαφορετικό πρόγραμμα περιήγησης
- Απενεργοποίηση αποκλεισμού αναδυόμενων παραθύρων
- Επαναφέρετε τη σύνδεση δικτύου
- Ανοίξτε την προεπιλεγμένη σελίδα του δρομολογητή
- Απενεργοποιήστε διακομιστές DNS τρίτων
- Ενεργοποίηση ανώνυμης λειτουργίας
- Ξεπλύνετε την προσωρινή μνήμη DNS μέσω γραμμής εντολών
- Ανανεώστε τη μίσθωση DHCP
- Απενεργοποιήστε προσωρινά το τείχος προστασίας
- Ενημερώστε το πρόγραμμα οδήγησης προσαρμογέα δικτύου
Σας προτείνουμε να δοκιμάσετε αυτές τις λύσεις διαδοχικά όπως παρουσιάζονται. Ωστόσο, είστε ελεύθεροι να το πάτε με οποιαδήποτε σειρά προτιμάτε.
Ας το κάνουμε σωστά, έτσι;
Επιδιόρθωση 1: Επανεκκινήστε τον υπολογιστή σας
Αυτή η λύση θα μπορούσε να είναι το μόνο που απαιτείται για την επίλυση του ζητήματος. Αυτό που πρέπει να κάνετε είναι:
- Αποσυνδεθείτε από το δίκτυο και απενεργοποιήστε το Wi-Fi.
- Αποσυνδεθείτε από τον λογαριασμό χρήστη στον υπολογιστή σας και τερματίστε το σύστημα.
- Ενεργοποιήστε ξανά τον υπολογιστή και συνδεθείτε ξανά στον λογαριασμό χρήστη σας.
- Ενεργοποιήστε το Wi-Fi και συνδεθείτε ξανά στο δίκτυο. Δείτε αν η σελίδα σύνδεσης θα εμφανιστεί τώρα στο πρόγραμμα περιήγησής σας.
Επιδιόρθωση 2: Χρησιμοποιήστε διαφορετικό πρόγραμμα περιήγησης
Εάν το πρόβλημα παραμένει μετά την επανεκκίνηση του υπολογιστή σας, η επόμενη καλύτερη επιλογή είναι να ορίσετε ένα άλλο πρόγραμμα περιήγησης, όπως το Microsoft Edge ή το Firefox, ως το προεπιλεγμένο πρόγραμμα περιήγησής σας. Ίσως θα εμφανιστεί τώρα η δεσμευμένη πύλη.
Μπορείτε να ακολουθήσετε αυτά τα βήματα:
- Μεταβείτε στο μενού Έναρξη (πατήστε το πλήκτρο λογότυπου των Windows στο πληκτρολόγιό σας).
- Πληκτρολογήστε «Πίνακας ελέγχου» στο πλαίσιο αναζήτησης. Η επιλογή θα εμφανιστεί ως Best Match. Κάντε κλικ σε αυτό.
- Επιλέξτε 'Κατηγορία' κάτω από το αναπτυσσόμενο μενού 'Προβολή ανά'.
- Εντοπίστε τα «Προγράμματα» και κάντε κλικ σε αυτό.
- Τώρα, κάντε κλικ στο Προεπιλεγμένα προγράμματα.
- Κάντε κλικ στην επιλογή 'Ορισμός των προεπιλεγμένων προγραμμάτων σας'.
- Περιμένετε να φορτωθεί η σελίδα. Στη συνέχεια, επιλέξτε το πρόγραμμα περιήγησης που θέλετε να χρησιμοποιήσετε και κάντε κλικ στην επιλογή 'Ορισμός αυτού του προγράμματος ως προεπιλογή'.
- Κάντε κλικ στο OK.
Μπορείτε να προχωρήσετε και να επανασυνδεθείτε στο δίκτυο Wi-Fi. Ξεκινήστε το νέο προεπιλεγμένο πρόγραμμα περιήγησης και δείτε αν θα εμφανιστεί η σελίδα σύνδεσης.
Σημείωση: Ίσως δεν χρειάζεται απαραίτητα να ορίσετε το νέο πρόγραμμα περιήγησης ως προεπιλογή. Απλώς ξεκινήστε το και δοκιμάστε να επισκεφθείτε έναν ιστότοπο. Θα μπορούσε να εμφανιστεί η δεσμευμένη πύλη.
Επιδιόρθωση 3: Απενεργοποίηση αποκλεισμού αναδυόμενων παραθύρων
Το πρόγραμμα περιήγησής σας μπορεί να έχει ρυθμιστεί ώστε να αποκλείει αναδυόμενα παράθυρα, ώστε να αποθηκεύει δεδομένα, να φορτώνει σελίδες πιο γρήγορα και επίσης να σας προστατεύει από την εμφάνιση ενοχλητικών διαφημίσεων όταν επισκέπτεστε έναν ιστότοπο. Ωστόσο, αυτό θα μπορούσε επίσης να εμποδίζει την εμφάνιση της δημόσιας σύνδεσης στο Wi-Fi.
Θα εξετάσουμε τώρα πώς να απενεργοποιήσουμε τον αποκλεισμό αναδυόμενων παραθύρων σε Chrome, Microsoft Edge και Firefox.
Χρώμιο:
- Εκκινήστε το πρόγραμμα περιήγησης και κάντε κλικ στο εικονίδιο με τις τρεις κουκκίδες στην επάνω δεξιά γωνία του παραθύρου.
- Κάντε κλικ στο Ρυθμίσεις από το μενού περιβάλλοντος.
- Κάντε κύλιση προς τα κάτω στο κάτω μέρος της σελίδας και κάντε κλικ στο αναπτυσσόμενο μενού 'Για προχωρημένους' για πρόσβαση σε περισσότερες ρυθμίσεις.
- Κάντε κλικ στο 'Ρυθμίσεις ιστότοπου' και μετακινηθείτε προς τα κάτω στο 'Αναδυόμενα παράθυρα και ανακατευθύνσεις'.
- Στη σελίδα που ανοίγει, απενεργοποιήστε την επιλογή 'Αποκλεισμένο (συνιστάται)' κάνοντας κλικ στο ρυθμιστικό στη δεξιά πλευρά. Στη συνέχεια, θα αλλάξει σε 'Επιτρέπεται'.
- Κλείστε την καρτέλα Ρυθμίσεις ή εκκινήστε ξανά το πρόγραμμα περιήγησής σας.
Microsoft Edge:
- Εκκινήστε το πρόγραμμα περιήγησης.
- Κάντε κλικ στο κουμπί «Περισσότερα» (το οριζόντιο εικονίδιο «τρεις κουκκίδες» στην επάνω δεξιά γωνία του παραθύρου).
- Κάντε κλικ στο Ρυθμίσεις και, στη συνέχεια, κάντε κλικ στο Απόρρητο και Ασφάλεια που εμφανίζεται στην αριστερή πλευρά.
- Θα βρείτε 'Αποκλεισμός αναδυόμενων παραθύρων' στην ενότητα Ασφάλεια. Κάντε κλικ στην εναλλαγή για να την απενεργοποιήσετε.
- Κλείστε την καρτέλα Ρυθμίσεις ή επανεκκινήστε το πρόγραμμα περιήγησης.
Firefox:
- Εκκινήστε το πρόγραμμα περιήγησης.
- Κάντε κλικ στο εικονίδιο Μενού (οι οριζόντιες τρεις κουκκίδες).
- Κάντε κλικ στις Προτιμήσεις> Περιεχόμενο.
- Αποεπιλέξτε το πλαίσιο ελέγχου για 'Αποκλεισμός αναδυόμενων παραθύρων'.
- Κλείστε την καρτέλα Προτιμήσεις ή επανεκκινήστε το πρόγραμμα περιήγησης.
Επίσης, αφού απενεργοποιήσετε την επιλογή στις ρυθμίσεις του προγράμματος περιήγησής σας, βεβαιωθείτε ότι έχετε απενεργοποιήσει οποιοδήποτε πρόγραμμα αποκλεισμού αναδυόμενων παραθύρων τρίτου μέρους που είναι ενεργό στον υπολογιστή σας.
Επιδιόρθωση 4: Επαναφέρετε τη σύνδεση δικτύου
Να τι πρέπει να κάνετε:
- Κάντε κλικ στο εικονίδιο Wi-Fi στην αριστερή γωνία της γραμμής εργασιών σας.
- Κάντε κλικ στην καρτέλα Wi-Fi για να την απενεργοποιήσετε.
- Ενεργοποιήστε ξανά τη σύνδεση δικτύου κάνοντας ξανά κλικ στο εικονίδιο Wi-Fi και στην καρτέλα Wi-Fi.
- Εκκινήστε το πρόγραμμα περιήγησής σας και δοκιμάστε να επισκεφθείτε το 'Google.com'. Η σελίδα σύνδεσης μπορεί τώρα να εμφανιστεί.
Εάν το πρόβλημα παραμένει αφού δοκιμάσετε και τις τέσσερις παραπάνω διορθώσεις, μην ανησυχείτε. Δεν θα είναι πολύ. Προχωρήστε στις άλλες λύσεις παρακάτω.
Επιδιόρθωση 5: Ανοίξτε την προεπιλεγμένη σελίδα του δρομολογητή
Ακολουθήστε αυτά τα εύκολα βήματα για να αποκτήσετε πρόσβαση στην προεπιλεγμένη σελίδα του δρομολογητή:
- Συνδεθείτε στο δημόσιο δίκτυο Wi-Fi.
- Ανοίξτε το πρόγραμμα περιήγησής σας.
- Πληκτρολογήστε οποιοδήποτε από τα ακόλουθα στη γραμμή URL και, στη συνέχεια, πατήστε Enter για να μεταβείτε στη σελίδα σύνδεσης του δρομολογητή:
- 0.0.1
- 168.1.1
- http: / localhost
- ότι
- το
Αυτό θα πρέπει να είναι αρκετό για να αναγκάσει την εμφάνιση της σελίδας σύνδεσης Wi-Fi. Αλλά σε περίπτωση που δεν λειτουργεί, θα πρέπει να αποκτήσετε χειροκίνητα τη διεύθυνση IP του συνδεδεμένου δρομολογητή και να την πληκτρολογήσετε στη γραμμή διευθύνσεων αντ 'αυτού. Στη συνέχεια, πατήστε Enter για να ανοίξετε τη σελίδα σύνδεσης.
Δείτε πώς μπορείτε να αποκτήσετε τη διεύθυνση IP του συνδεδεμένου δρομολογητή:
- Ανοίξτε το παράθυρο διαλόγου Εκτέλεση. Μπορείτε να το κάνετε πατώντας το πλήκτρο λογότυπου των Windows + συνδυασμό R στο πληκτρολόγιό σας.
- Πληκτρολογήστε 'CMD' στο πεδίο κειμένου και πατήστε Enter ή κάντε κλικ στο κουμπί Ok για να ανοίξετε το παράθυρο γραμμής εντολών.
- Πληκτρολογήστε 'ipconfig' (βεβαιωθείτε ότι δεν συμπεριλαμβάνετε τα ανεστραμμένα κόμματα) και πατήστε Enter.
- Εντοπίστε τη διεύθυνση IPv4 που εμφανίζεται στην ενότητα 'Wi-Fi προσαρμογέα ασύρματου LAN:'
- Τώρα, αντιγράψτε και επικολλήστε τη διεύθυνση στη γραμμή διευθύνσεων URL του προγράμματος περιήγησής σας και πατήστε Enter. Στη συνέχεια, θα μπορείτε να περιηγηθείτε στο Διαδίκτυο χωρίς περαιτέρω πρόβλημα.
Επιδιόρθωση 6: Απενεργοποίηση διακομιστών DNS τρίτων
Ένας διακομιστής DNS τρίτου μέρους (Σύστημα ονομάτων τομέα), όπως το Dyn, ο διακομιστής δημόσιου DNS Google και ούτω καθεξής, μπορεί μερικές φορές να περιορίσει την κατάλληλη σύνδεση σε δημόσιο Wi-Fi.
Εάν αυτό ισχύει στην περίπτωσή σας, δηλαδή εάν έχετε διακομιστή DNS τρίτου μέρους στον υπολογιστή σας, μπορείτε να επιλύσετε το πρόβλημα απενεργοποιώντας τον.
Ακολουθήστε τα παρακάτω εύκολα βήματα για να το ολοκληρώσετε.
Σημείωση: Γνωρίζουμε τους ιστότοπους με τα ονόματα τομέα που είναι αναγνώσιμα από τον άνθρωπο, όπως το Google.com. Ο σκοπός του συστήματος ονομάτων τομέα (DNS) είναι η μετάφραση αυτών των ονομάτων τομέα σε διευθύνσεις IP (Internet Protocol) όπως 173.194.39.78, ώστε το πρόγραμμα περιήγησής σας να μπορεί να φορτώνει τον ιστότοπο. Έτσι, το DNS αναφέρεται συχνά ως τηλεφωνικός κατάλογος του Διαδικτύου επειδή συνδέει διευθύνσεις URL με τις διευθύνσεις IP τους.
- Πατήστε το πλήκτρο με το λογότυπο των Windows + I στο πληκτρολόγιό σας για να ανοίξετε την εφαρμογή Ρυθμίσεις.
- Κάντε κλικ στο Δίκτυο και Διαδίκτυο.
- Κάντε κλικ στο «Άνοιγμα δικτύου και κοινής χρήσης».
- Κάντε κλικ στο όνομα του δημόσιου δικτύου Wi-Fi.
- Στην καρτέλα που ανοίγει, κάντε κλικ στο κουμπί Ιδιότητες.
- Στη νέα καρτέλα που ανοίγει, στην ενότητα 'Αυτή η σύνδεση χρησιμοποιεί τα ακόλουθα στοιχεία', επιλέξτε 'Internet Protocol Version 4 (TCP / IPv4)' και κάντε κλικ στο κουμπί Properties.
- Ενεργοποιήστε τις ακόλουθες επιλογές: «Λήψη αυτόματης διεύθυνσης IP» και «Απόκτηση διεύθυνσης διακομιστή DNS αυτόματα».
Τώρα μπορείτε να ανοίξετε το πρόγραμμα περιήγησής σας και να ελέγξετε εάν θα εμφανιστεί η δεσμευμένη πύλη του Wi-Fi.
Επιδιόρθωση 7: Ενεργοποίηση ανώνυμης λειτουργίας
Ίσως το πρόγραμμα περιήγησής σας να μην φορτώνει τη σελίδα σύνδεσης επειδή προσπαθεί να χρησιμοποιήσει τις αποθηκευμένες πληροφορίες DNS.
Η κατάσταση ανώνυμης περιήγησης ή η ιδιωτική περιήγηση ξεχνά τα δεδομένα περιήγησής σας, όπως cookie, προσωρινή μνήμη, φόρμες αυτόματης συμπλήρωσης και ούτω καθεξής. Έτσι, θα μπορούσε να αφήσει τη σελίδα σύνδεσης να φορτωθεί με επιτυχία.
Η κατάσταση ανώνυμης περιήγησης είναι διαθέσιμη ανεξάρτητα από το πρόγραμμα περιήγησης που χρησιμοποιείτε, είτε πρόκειται για Edge, Chrome, Firefox, Opera ή Safari.
Να λοιπόν αυτό που πρέπει να κάνετε:
- Εκκινήστε το πρόγραμμα περιήγησής σας και ανοίξτε ένα νέο παράθυρο ανώνυμης περιήγησης (Κάντε κλικ στο εικονίδιο Μενού και επιλέξτε 'Νέο παράθυρο ανώνυμης περιήγησης'). Για να το κάνετε γρήγορα στο Chrome, απλώς πατήστε Ctrl + Shift + N στο πληκτρολόγιό σας.
- Μεταβείτε στη γραμμή διευθύνσεων URL και πληκτρολογήστε τη διεύθυνση ενός ιστότοπου που δεν είναι HTTPS (com, για παράδειγμα) και, στη συνέχεια, πατήστε Enter.
Αφού εκτελέσετε αυτά τα βήματα, η σελίδα σύνδεσης θα αναγκαστεί να εμφανιστεί.
Επιδιόρθωση 8: Ξεπλύνετε την προσωρινή μνήμη DNS
Η διεύθυνση IP του δρομολογητή του δημόσιου Wi-Fi ενδέχεται να άλλαξε πρόσφατα. Και τα Windows ενδέχεται να έχουν αποθηκεύσει τις παλιές πληροφορίες στην προσωρινή μνήμη DNS. Σε αυτήν την περίπτωση, η σελίδα σύνδεσης δεν θα φορτωθεί. Επομένως, θα πρέπει να ξεπλύνετε την προσωρινή μνήμη DNS μέσω της γραμμής εντολών για να επιλύσετε το πρόβλημα.
Σημείωση: Όπως έχει ήδη εξηγηθεί στην Επιδιόρθωση 6 παραπάνω, οι διακομιστές DNS είναι υπεύθυνοι για τη μετατροπή ονομάτων τομέα όπως www.example.com σε αριθμητικές διευθύνσεις IP που μπορούν να διαβαστούν από το πρόγραμμα περιήγησής σας πριν από τη φόρτωση του ιστότοπου.
Μια προσωρινή μνήμη DNS (μερικές φορές αναφέρεται ως προσωρινή μνήμη DNS), από την άλλη πλευρά, είναι μια προσωρινή βάση δεδομένων στην οποία το λειτουργικό σύστημα του υπολογιστή σας καταγράφει όλους τους ιστότοπους και άλλους τομείς διαδικτύου που έχετε επισκεφτεί ή επιχειρήσατε να επισκεφθείτε πρόσφατα. Είναι βασικά μια μνήμη των πρόσφατων αναζητήσεων DNS στις οποίες μπορεί να αναφέρεται ο υπολογιστής σας όταν προσπαθείτε να προσδιορίσετε πώς να φορτώσετε έναν ιστότοπο.
Ακολουθήστε αυτά τα εύκολα βήματα για να ξεπλύνετε την προσωρινή μνήμη DNS:
- Πατήστε το πλήκτρο λογότυπου των Windows + συνδυασμός R στο πληκτρολόγιό σας για να ανοίξετε το παράθυρο διαλόγου Εκτέλεση.
- Πληκτρολογήστε 'CMD' στο πεδίο κειμένου και πατήστε Enter ή κάντε κλικ στο OK.
- Όταν τελειώσετε, πληκτρολογήστε 'ipconfig / flushdns' και πατήστε Enter για να εκκαθαρίσετε την προσωρινή μνήμη DNS. Περιμένετε να ολοκληρωθεί η διαδικασία.
- Κλείστε το παράθυρο γραμμής εντολών και, στη συνέχεια, εκκινήστε το πρόγραμμα περιήγησής σας. Δείτε αν θα εμφανιστεί τώρα η σελίδα σύνδεσης του Wi-Fi.
Επιδιόρθωση 9: Ανανεώστε τη μίσθωση DHCP
Η διεύθυνση IP που εκμισθώθηκε στον υπολογιστή σας από το δημόσιο δρομολογητή Wi-Fi ενδέχεται να έχει λήξει και αυτός είναι ο λόγος για τον οποίο δεν εμφανίζεται η δεσμευμένη πύλη.
Θα πρέπει να παραγγείλετε τον πελάτη DHCP (Dynamic Host Configuration Protocol) για να διαπραγματευτείτε εκ νέου μια άλλη μίσθωση με τον διακομιστή DHCP στο δρομολογητή, ώστε να μπορεί να συνδεθεί ο υπολογιστής σας. Αυτό γίνεται μέσω της γραμμής εντολών. Δείτε πώς:
- Ανοίξτε το παράθυρο διαλόγου Εκτέλεση πατώντας το συνδυασμό λογότυπου Windows + R στο πληκτρολόγιό σας.
- Πληκτρολογήστε 'CMD' στο πλαίσιο κειμένου και πατήστε Enter ή κάντε κλικ στο κουμπί Ok.
- Στο παράθυρο γραμμής εντολών που ανοίγει, πληκτρολογήστε 'ipconfig / release' (Μην συμπεριλάβετε τα ανεστραμμένα κόμματα) και πατήστε Enter για να το εκτελέσετε. Αυτό απελευθερώνει την τρέχουσα διαμόρφωση IP. Περιμένετε να ολοκληρωθεί η διαδικασία. Μπορεί να πάρει λίγο χρόνο.
- Τώρα, πληκτρολογήστε 'ipconfig / renew' και πατήστε Enter. Ο διακομιστής DHCP (Dynamic Host Configuration Protocol) θα εκχωρήσει στον υπολογιστή σας μια νέα διεύθυνση IP. Περιμένετε να ολοκληρωθεί η διαδικασία.
- Κλείστε το παράθυρο γραμμής εντολών.
- Αποσυνδεθείτε από το δημόσιο δίκτυο Wi-Fi και, στη συνέχεια, συνδεθείτε ξανά σε αυτό.
- Εκκινήστε το πρόγραμμα περιήγησής σας και δείτε εάν θα εμφανιστεί τώρα η σελίδα σύνδεσης.
Επιδιόρθωση 10: Απενεργοποιήστε προσωρινά το τείχος προστασίας
Το Τείχος προστασίας των Windows διατηρεί τον υπολογιστή σας ασφαλή από απειλές φιλτράροντας τις μεταδόσεις δεδομένων δικτύου. Αποκλείει κακόβουλες επικοινωνίες και προγράμματα που τα ξεκινούν. Αλλά θα μπορούσε να είναι ο λόγος για τον οποίο δεν μπορείτε να αποκτήσετε πρόσβαση στη σελίδα σύνδεσης του δημόσιου Wi-Fi. Δοκιμάστε να το απενεργοποιήσετε για να το ξέρετε σίγουρα.
Δείτε πώς:
- Πατήστε το συνδυασμό πλήκτρων με το λογότυπο των Windows + R στο πληκτρολόγιό σας για να ενεργοποιήσετε το παράθυρο διαλόγου Εκτέλεση.
- Πληκτρολογήστε 'control firewall.cpl' στο πεδίο κειμένου και πατήστε Enter ή κάντε κλικ στο Ok. Αυτό σας οδηγεί στη σελίδα του Τείχους προστασίας στον Πίνακα Ελέγχου.
- Στην αριστερή πλευρά του παραθύρου, θα βρείτε την επιλογή 'Ενεργοποίηση ή απενεργοποίηση του τείχους προστασίας του Windows Defender.' Κάντε κλικ σε αυτό.
- Στη νέα σελίδα που ανοίγει, μεταβείτε στην κατηγορία Ρυθμίσεις δημόσιου δικτύου και επιλέξτε «Απενεργοποίηση του τείχους προστασίας του Windows Defender (Δεν συνιστάται)» και, στη συνέχεια, κάντε κλικ στο κουμπί OK.
- Επανεκκινήστε τον υπολογιστή σας, επανασυνδεθείτε στο δίκτυο Wi-Fi και εκκινήστε το πρόγραμμα περιήγησής σας. Δείτε αν θα εμφανιστεί τώρα η σελίδα σύνδεσης.
Σημείωση: Για να διατηρήσετε τον υπολογιστή σας ασφαλή, βεβαιωθείτε ότι έχετε ενεργοποιήσει ξανά το Τείχος προστασίας των Windows. Ακολουθήστε τα ίδια παραπάνω βήματα για να το κάνετε, αλλά αντίθετα επιλέξτε 'Ενεργοποίηση του τείχους προστασίας του Windows Defender' στην περιοχή Δημόσιο δίκτυο.
Επιδιόρθωση 11: Ενημέρωση του προγράμματος οδήγησης προσαρμογέα δικτύου
Εάν έχετε δοκιμάσει όλες τις παραπάνω επιδιορθώσεις, αλλά δεν μπορείτε να χρησιμοποιήσετε το Διαδίκτυο, πρέπει να βεβαιωθείτε ότι το πρόγραμμα οδήγησης προσαρμογέα δικτύου είναι ενημερωμένο.
Σας συνιστούμε να χρησιμοποιήσετε το Driver Updater για να το χειριστείτε αυτόματα. Το εργαλείο θα διαβάσει τις προδιαγραφές του υπολογιστή σας και στη συνέχεια θα πραγματοποιήσει πλήρη σάρωση για να εντοπίσει ξεπερασμένα, χαμένα, ασυμβίβαστα ή κατεστραμμένα προγράμματα οδήγησης στον υπολογιστή σας. Στη συνέχεια, αφού του δώσετε άδεια, κατεβάζει και εγκαθιστά την τελευταία έκδοση των προγραμμάτων οδήγησης, όπως συνιστάται από τον κατασκευαστή του υπολογιστή σας.
Ωστόσο, εάν είστε βέβαιοι ότι το πρόγραμμα οδήγησης προσαρμογέα δικτύου είναι ήδη ενημερωμένο και η δεσμευμένη πύλη εξακολουθεί να μην εμφανίζεται, η απεγκατάσταση και επανεγκατάσταση του προγράμματος οδήγησης θα σας βοηθήσει να διορθώσετε τυχόν κατεστραμμένα αρχεία.
Ακολουθήστε αυτά τα εύκολα βήματα:
- Πατήστε το συνδυασμό λογότυπου Windows + R στο πληκτρολόγιό σας για να εμφανιστεί το παράθυρο διαλόγου Εκτέλεση.
- Πληκτρολογήστε 'devmgmt.msc' στο πλαίσιο κειμένου και κάντε κλικ στο Ok ή πατήστε Enter για να ανοίξετε τη Διαχείριση συσκευών.
- Τώρα, μετακινηθείτε προς τα κάτω στο Network Adapters και κάντε κλικ στο βέλος για να επεκτείνετε την επιλογή.
- Κάντε δεξί κλικ στον προσαρμογέα δικτύου σας και κάντε κλικ στην επιλογή 'Κατάργηση εγκατάστασης συσκευής' από το μενού περιβάλλοντος.
- Επανεκκινήστε τον υπολογιστή σας. Το πρόγραμμα οδήγησης θα επανεγκατασταθεί αυτόματα. Εάν όμως τα Windows δεν το κάνουν, επιστρέψτε στη Διαχείριση συσκευών. Κάντε κλικ στην καρτέλα Ενέργεια και, στη συνέχεια, κάντε κλικ στην επιλογή Σάρωση για αλλαγές υλικού. Στη συνέχεια θα εγκατασταθεί το πρόγραμμα οδήγησης.
- Επανεκκινήστε τον υπολογιστή σας, συνδεθείτε στο δημόσιο δίκτυο Wi-Fi, ξεκινήστε το πρόγραμμα περιήγησής σας και, στη συνέχεια, δείτε εάν θα εμφανιστεί τώρα η σελίδα σύνδεσης.
Εάν η δεσμευμένη πύλη εξακολουθεί να αρνείται να εμφανιστεί αφού δοκιμάσετε όλες τις παραπάνω λύσεις, είναι πιθανό το Wi-Fi να είναι εκτός λειτουργίας. Ρωτήστε οποιονδήποτε γύρω σας εάν αντιμετωπίζει το ίδιο πρόβλημα. Εάν ναι, εξετάστε το ενδεχόμενο να το αναφέρετε στη διεύθυνση, ώστε να μπορούν να την αντιμετωπίσουν από το τέλος τους. Ο δρομολογητής μπορεί απλά να χρειάζεται επανεκκίνηση.
Ελπίζουμε ότι έχετε καταφέρει να ξεπεράσετε αυτό το ζήτημα και τώρα μπορείτε να σερφάρετε στο Διαδίκτυο χρησιμοποιώντας το δημόσιο Wi-Fi. Οι λύσεις που έχουμε παρουσιάσει εδώ θα διασφαλίσουν ότι μπορείτε να το κάνετε αυτό.
Εάν έχετε οποιεσδήποτε ερωτήσεις ή σχόλια, μη διστάσετε να τα μοιραστείτε στην παρακάτω ενότητα.
Θα θέλαμε να σας ενημερώσουμε.
