Το Android 3.0 Honeycomb εκτός από την υποστήριξη για tablet UI και μια νέα ακόμα έκδοση του Android, έρχεται με επιπλέον καλούδια όπως το Android Fragments API. Με το νέο API το Google όχι μόνο αναγνωρίζει το πρόβλημα που έχει δημιουργηθεί με διαφορετικά μοντέλα κινητών και τις διαφορετικές αναλύσεις αλλά προσπαθεί να κάνει κάτι για αυτό. Στο Android Fragments API δίνεται η δυνατότητα στους developers να παρουσιάσουν το Android app σε ένα πλήθος διαφορετικών συσκευών, ακόμα και αυτών που τρέχουν Android 1.6. Αυτό σημαίνει ότι όσοι developers αποφασίσουν να χρησιμοποιήσουν το Android Fragments API θα έχουν την δυνατότητα να τρέξουν τις εφαρμογές τους ακόμα και σε κινητά με Android 1.6 ή σε αυτά που έχον χαμηλή ανάλυση και μέγεθος οθόνης. Αν ανταποκριθούν ή όχι, έγκαιρα ή ετεροχρονισμένα είναι κάτι που θα το μάθουμε σε μερικούς μήνες. Προς το παρόν η αγορά του Android παραμένει ανώριμη και κατακερματισμένη. 0 ΣΧΟΛΙΑ
