Σε άμεσες και δραστικές ενέργειες είναι αποφασισμένη να προχωρήσει για την απομάκρυνση των κεραιών κινητής τηλεφωνίας η δημοτική Αρχή. Από σήμερα οι πολίτες θα μπορούν να κάνουν τις καταγγελίες τους στο τηλέφωνο 22410-32722 στη δημοτική αστυνομία, οι οποίες θα καταγράφονται και θα ερευνώνται. Η δημοτική αστυνομία αναμένεται να δεχθεί καταιγισμό τηλεφωνημάτων, αφού οι πολίτες που ανακαλύπτουν διαρκώς ότι έχουν δίπλα τους κεραίες κινητής τηλεφωνίας, είναι έντονα θορυβημένοι και φέρονται αποφασισμένοι να διεκδικήσουν δυναμικά την άμεση απομάκρυνσή τους. Αρκετοί συμπολίτες μας τονίζουν μάλιστα ότι δεν έχουν τα περιθώρια να περιμένουν το δήμο να κινήσει τις διαδικασίες για να ξηλωθούν οι κεραίες, αφού αναμένεται να είναι χρονοβόρες οι διαδικασίες. Σε πλήρη ετοιμότητα να προβούν σε δυναμικές κινητοποιήσεις είναι οι κάτοικοι της Ανάληψης, αφού έχουν διαπιστώσει ότι υπάρχουν δίπλα τους τρεις παράνομες κεραίες κινητής τηλεφωνίας. Καθώς, οι διαδικασίες μέσω του Δήμου αναμένεται να είναι χρονοβόρες, οι κάτοικοι της Ανάληψης, που ανησυχούν έντονα για τις επιπτώσεις που έχει η ηλεκτρομαγνητική ακτινοβολία στην υγεία τους, δεν έχουν καμία διάθεση να επιτρέψουν να συνεχίζεται η έκθεση τους σε αυτούς τους κινδύνους. Το δρόμο τον έδειξαν άλλωστε οι κάτοικοι της περιοχής του Ροδινιού, που με τη μαζική τους κινητοποίηση κατάφεραν να ξηλωθεί κεραία εταιρείας κινητής τηλεφωνίας μέσα σε λίγα εικοσιτετράωρα.
