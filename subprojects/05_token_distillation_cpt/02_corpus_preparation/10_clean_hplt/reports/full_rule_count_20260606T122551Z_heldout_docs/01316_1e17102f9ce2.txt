Πώς θα γίνεις η καλύτερη εκδοχή του εαυτού σου; Πώς θα μπορέσεις να εξελιχθείς και να γίνεις καλύτερος; Η απάντηση δεν κρύβεται στα βιβλία. Η απάντηση κρύβεται σε εσένα τον ίδιο. Θα πρέπει να μάθεις να αξιολογείς τον εαυτό σου. Μόνο έτσι θα διαπιστώσεις τι σε κρατάει πίσω, τι πάει καλά και τι όχι και το σημαντικότερο; Τι πρέπει να βελτιώσεις για να μπορέσεις να εξελιχθείς και να καταφέρεις να κάνεις βήματα προς τα μπροστά.
