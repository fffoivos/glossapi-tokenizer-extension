Κηπος Οι επιλογές είναι πολλές για το πώς θα διαμορφώσετε τον χώρο και τι θα καλλιεργήσετε είτε πρόκειται για έναν αστικό λαχανόκηπο είτε για ένα τροπικό παράδεισο μέχρι και την επιλογή ιδιαίτερων γλαστρών. Έχοντας εξετάσει τη λειτουργικότητα του χώρου σας, ακολουθούν μερικές σχεδιαστικές συμβουλές που θα σας βοηθήσουν να μεγιστοποιήσετε πραγματικά τις δυνατότητές του και να δημιουργήσετε την ψευδαίσθηση ενός πολύ μεγαλύτερου κήπου. Οι λευκοί κήποι ή αλλιώς οι κήποι του φεγγαριού περιλαμβάνουν φυτά με λευκά άνθη και φυτά με ασημί φύλλωμα, δημιουργώντας μια αίσθηση μυστηρίου και ρομαντισμού. Μια πλαϊνή αυλή τείνει να είναι ένας σκοτεινός και στενός χώρος. Επιλέξτε φυτά που μπορούν να πάρουν βαθιά σκιά ή επικεντρωθείτε κυρίως σε λύσεις με λιγότερη συντήρηση. Μια πλαϊνή αυλή θεωρείται κυρίως ως μια διαδρομή μεταξύ της μπροστινής και της πίσω αυλής. Η περιοχή τείνει να είναι σκοτεινή και στενή και παρουσιάζει μοναδικές σχεδιαστικές προκλήσεις, επομένως συχνά χάνεται η δυνατότητα δημιουργίας ενός ελκυστικού και λειτουργικού χώρου. Οι κήποι με βότανα σε γλάστρες - ζρντινιέρες μπορούν να καλλιεργηθούν σε σχεδόν οποιοδήποτε φυτοδοχείο θέλετε. Μπορείτε να φυτέψετε αρωματικά και βότανα σε γλάστρες σε μια ηλιόλουστη βεράντα ή κοντά στην κουζίνα σας για εύκολη πρόσβαση.
