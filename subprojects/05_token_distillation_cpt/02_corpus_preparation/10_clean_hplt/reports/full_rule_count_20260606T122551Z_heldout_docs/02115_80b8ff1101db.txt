Οι αστρολογικές προβλέψεις των ζωδίων αυτή την εβδομάδα από τον Χρήστο Άρχο. Ο Ερμής αλλάζει κατεύθυνση και αρχίζουν να υπάρχουν σημαντικές εξελίξεις σε θέματα επιχειρηματικών κινήσεων και επαφών. Τα περισσότερα ζώδια νοιώθουν περισσότερο ελεύθερα να κινηθούν και η εβδομάδα έχει σημαντικές εξελίξεις . Ακολουθούν οι προβλέψεις για αυτή την εβδομάδα 3/10 – 9/10: Κριός: Για εσάς είναι μία περίοδος μεγαλύτερης επίτευξης σε θέματα οικονομικά και επαγγελματικά θα καταφέρετε αν προσπαθήσετε μέχρι τη Τετάρτη να κάνετε μία πολύ σημαντική συμφωνία που θα σας βοηθήσει να επιλύσετε πολλά θέματα που έχετε στο μυαλό και θα μπορέσετε να κλείσετε κακώς κείμενα στις διαπροσωπικές σας σχέσεις. Ταύρος: Οικονομικά θα παρουσιάσετε κάποιες δυσκολίες και θα αγχωθείτε στο πως θα αντιμετωπίσετε την καθημερινότητα με ξαφνικά έξοδα και υπερβολές που θα σας πιέσουν αρκετά. Από την άλλη όμως είναι μία περίοδος μεγάλων προοπτικών στα αισθηματικά με νέες σχέσεις που θα σας συγκλονίσουν και θα σας κάνουν να περάσετε υπέροχα Δίδυμοι: Με αρκετά νεύρα ξεκινάει αυτή η εβδομάδα και θα μπορέσετε να δημιουργήσετε ένα καινούριο πλαίσιο εργασίας και λειτουργίας μετά από τις προσωπικές αποκαλύψεις που έχετε το τελευταίο καιρό. Στο σπίτι υπάρχουν κάποιες όμορφες συναντήσεις και επαφές που θα σας κάνουν να περνάτε όμορφα και θα σας βοηθήσουν να χαλαρώσετε. Καρκίνος: Μακριά από υπερβολές και προβλήματα είναι μία εβδομάδα που θα σας βοηθήσει να χαλαρώσετε. Αρχικά στο οικονομικό σας κομμάτι έρχονται κάποιες ευκαιρίες ενώ κάποια ταξίδια που είχαν ακυρωθεί επιτέλους μπορούν να προχωρήσουν! Ίσως κάποια άτομα που είναι εξωτερικά φιλικά θέλουν να σας δημιουργήσουν προβλήματα! Λέων: Χρήματα έρχονται ύστερα από αρκετές καθυστερήσεις και μπορείτε να περιμένετε την λήξη κάποιων πολύ σημαντικών προβλημάτων στην καθημερινή σας ζωή. Σε θέματα φιλικών σχέσεων όμως θα έχετε κάποια προβλήματα καθότι παρεξηγήσεις και περιστασιακές εντάσεις μπορεί να προκαλέσουν σημαντικές κρίσεις στη καθημερινότητα Παρθένος: Χωρίς ιδιαίτερα προβλήματα αυτή η εβδομάδα θα καταφέρετε να χτίσετε ένα καινούριο πλαίσιο στη δουλειά σας και στη ζωή σας καθότι καταρρέουν πολλά εμπόδια και θα νοιώσετε ότι έχετε επιτέλους βρει τον εαυτό σας. Ταραχές στη δουλειά σας μπορεί να σας πιέσουν λίγο αλλά θα καταφέρετε να βρείτε την ισορροπία σας. Ζυγός: Συνεχίζει η περίοδος να είναι ερωτική και να προσφέρει πολλά πράγματα στη καθημερινότητα σας. Αν είσαστε μόνοι μία νέα σχέση μπορεί να σας συναρπάσει ενώ η δημιουργικότητα σας θα είναι σε πολύ υψηλό βαθμό! Προσοχή σε θέματα σπουδών καθότι κάτι μπορεί να μην το έχετε λάβει σοβαρά υπόψιν σας. Σκορπιός: Μία κρυφή ερωτική σχέση μπορεί να δημιουργηθεί ενώ και γενικά η αισθηματική σας ζωή θα είναι πολύ πιο ενδιαφέρουσα και δυνατή. Προσοχή σε θέματα οικονομικά καθότι μπορεί να υπάρξουν κάποιες απώλειες και πιέσεις. Σε κληρονομικά ζητήματα μπορεί να συναντήσετε εμπόδια και καθυστερήσει. Τοξότης: Ένας νέος ερωτικός σύντροφος μπορεί να σας ταράξει και να σας αλλάξει τη καθημερινότητα. Προσοχή στις οικονομικές σας επιλογές καθότι μπορεί να βρεθείτε σε ξαφνικά εμπόδια και υπερβολικές απαιτήσεις από τρίτους. Περίοδος απαιτήσεων στη δουλειά μπορείτε να δείξετε όμως τα ταλέντα σας Αιγόκερως: Ο τομέας της εργασίας θα είναι λίγο πιεσμένος και θα νοιώσετε αρκετά αγχωμένοι παρόλα αυτά μπορείτε να πετύχετε πολλά και να αλλάξετε τη ζωή σας. Να μην πέσετε θύμα υπερβολικής εργασίας με αποτέλεσμα την υπερκόπωση. Ένα ευχάριστο ταξίδι θα σας φτιάξει τη διάθεση και μία επιτυχία έρχεται σε δικαστικά/ νομικά θέματα. Υδροχόος: Μία νέα ερωτική σχέση έρχεται να σας συναρπάσει και να σας συγκλονίσει. Είσαστε αρκετά δημιουργικοί και μπορείτε να κάνετε υπέροχες κινήσεις για να λύσετε κάποιο μακροπρόθεσμο πρόβλημα που ταλαιπωρούσε εσάς και τα παιδιά σας. Οικονομικά έρχεται μία πολύ σημαντική στήριξη και σας βοηθά να αλλάξετε τα δεδομένα. Ιχθύες: Μία σχέση έρχεται αρκετά συνταρακτική ενώ μπορείτε να περιμένετε και επανασυνδέσεις αυτή τη περίοδο. Επιτέλους νοιώθετε ελεύθεροι να κάνετε αυτό που έχετε βάλει στο μυαλό σας ενώ προσοχή χρειάζεται ο χώρος του σπιτιού με βλάβες που θα κοστίσουν αλλά και με εντάσεις με το οικογενειακό περιβάλλον.
