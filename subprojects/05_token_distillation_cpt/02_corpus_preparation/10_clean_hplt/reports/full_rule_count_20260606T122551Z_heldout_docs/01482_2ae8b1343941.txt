CyberStream και Matillion προσφέρουν καινοτόμες λύσεις Data ETL / ELT H CyberStream αναλαμβάνει τη διανομή και υποστήριξη των προϊόντων ETL/ELT της Matillion. Η καινοτόμος και βραβευμένη πλατφόρμα ETL/ELT της Matillion είναι τώρα διαθέσιμη σε κάθε επιχείρηση ή οργανισμό που επιθυμεί να αξιοποιήσει τη νέα τεχνολογική τάση υλοποίησης σύγχρονων Cloud Data Warehouses (CDW) και Data Lakes (DL) σε περιβάλλοντα υπολογιστικού νέφους, όπως είναι το Azure της Microsoft, το AWS της Amazon, το Google Cloud, κ.α. Το Matillion ETL / Data Loader, μεταξύ άλλων, υποστηρίζει:
- Τη φόρτωση δεδομένων σε CDW / Data Lakes όπως είναι οι Snowflake, Amazon Redshift, Google BigQuery, Azure Synapse Analytics, Databricks Delta Lake.
- Τη φόρτωση δεδομένων από πρωτογενείς πηγές, όπως σχεσιακές βάσεις δεδομένων, από περισσότερους από 100 κατασκευαστές.
- Τη γρήγορη και εύκολη δημιουργία ροών (data pipelines) που συνδέουν τις πρωτογενείς πηγές με τις πλέον εδραιωμένες πλατφόρμες cloud data.
- Την ταχεία ενσωμάτωση και μετασχηματισμό δεδομένων σε σχήματα κατάλληλα για εφαρμογές BI, Data Science, Οπτικοποίησης και Ανάλυσης Δεδομένων.
- Τον «εκδημοκρατισμό» των δεδομένων, μέσω της απρόσκοπτης και απλής διαδικασίας πρόσβασης σε αυτά, όλων των χρηστών, κάθε επιπέδου.
Το Matillion ETL / Data Loader συμπληρώνει στρατηγικά τις λύσεις και υπηρεσίες που προσφέρει η CyberStream στην περιοχή των Big Data Analytics (http:/www.cyberstream.gr/solutions/analytics) και προσθέτει ένα κρίσιμο εργαλείο υψηλής εξειδίκευσης στη διάθεση των πελατών της που προσανατολίζονται σε υποδομές cloud.
