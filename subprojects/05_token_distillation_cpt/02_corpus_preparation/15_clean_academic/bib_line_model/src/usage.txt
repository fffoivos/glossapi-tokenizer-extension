bib_line_detect — Greek bibliography line classifier (Rust port of heading_lexgate)

  bib_line_detect emit-table --input <docs.jsonl> --out <table.npy>
      Emit the 116 deterministic columns (10..126 of feature contract v3) for every
      line, in document order. For parity-checking against the deployed features.npy.

  bib_line_detect detect --artifacts <dir> --input <docs.jsonl> --out <spans.jsonl>
      Score lines and emit bibliography spans.  [model layers pending]

Input: one JSON object per line with a `lines` array of {text, abs_idx}.
