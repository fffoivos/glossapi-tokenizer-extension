# Greek Academic CPT Corpus — Reference/Citation Cleaning Plan (decision-ready)

## Executive answer
The corpus goal is **plain Greek language modeling for Apertus CPT** (not citation graphs / retrieval / scholarly QA), so the essay's REMOVE/MASK/STRUCTURE taxonomy collapses cleanly: **STRUCTURE is out** (no consumer, links unrecoverable from OCR), and the choice is **REMOVE end-matter (by segmentation) + handle in-text markers (mostly keep-and-count)**. None of the six evaluated methods translates literally — the verdict is **needs-adaptation for the three that share our goal (peS2o-intent, MEDITRON-delete-end-matter, the taxonomy, the OCR-Greek posture) and translates-poorly for the three whose mechanism we cannot or should not run (MEDITRON-summary-mask, S2ORC-link, sci-writing-substitution).**

The single most consequential finding, verified again this session: **the dominant reference token sink in humanities theses is NOT the end-matter list but the body-interleaved footnote stream** (006: 1019 footnote lines = 22.4% of the doc vs ~4.4% end-bib; 086: 233 footnote lines before the bib header vs 2 after). A peS2o/MEDITRON end-reference removal is necessary-but-far-from-sufficient — it misses most of the mass where it matters most, and the footnote stream is **dual-content** (verified: 006 fn14 is pure discursive Greek, fn13 right next to it is pure Latin citation), so blanket removal destroys 21-29% genuine Greek LM signal.

## Verdict: REMOVE (by segmentation) / MASK / STRUCTURE
- **REMOVE** end-matter and footnote-stream reference mass — but realized as **SEGMENT + per-family COUNT + reversible sidecar + user-controlled drop knob**, never hard-delete and never a baked threshold. Drop "harder" only where the text is genuinely Latin-saturated low-Greek-signal (STEM/medical) — content-gated, because 006's end-bib is dense polytonic/katharevousa **Greek** archival titles we want to keep.
- **MASK** to a `<ref>` token: rejected. Even the degenerate summary-free variant introduces a new mid-prose token into an existing Apertus tokenizer (fertility risk) and corrupts OCR'd inline digits. In-text markers are kept-and-counted.
- **STRUCTURE** (S2ORC link / MEDITRON summary): rejected. No downstream consumer, no marker→entry linkage, OCR'd numbered indices are corrupted/reordered, and summary injection fabricates non-source Greek + violates Rust-by-default at 55B-tok scale.

## Per-source design
See per_source_design. One Rust reference module (one detector, many consumers) feeds from two structuring layers: **free `predicted_section=β` column** (kallipos/pergamos) vs **a header-segmentation pass via the existing GlossSection + classifier** (greek_phd/openarchives — no PDFs on disk, GROBID unrunnable). Every source emits the same auditable `.refspans.jsonl` sidecar + per-signal `counters.parquet`, with keep/drop as a user knob.

## Risks + guardrails (folded in from adversarial verification)
1. **Boundary over-segmentation** — 000's TOC row `## Βιβλιογραφία` + `(σελ. 1029-1163)` would amputate 99.4% of the doc (verified). Guard: lower-doc position + TOC/dot-leader rejection + colophon/lit-review deny + take LAST qualifying header + content-confirm year-density + **fail-closed** (keep text on disagreement).
2. **β not clean enough to drop blindly** (~0.85-0.90; verified Kallipos FPs Προαπαιτούμενη γνώση/Λέξεις-κλειδιά/Απάντηση/colophon; Pergamos front-CV β in 36.7% of docs, 24-26% zero-year, 72.5-73.8% headers no-keyword). Guard: per-section citation-shape SCORE + positional guard + CV-header keep-list; emit a `beta_kept_as_non_bib` audit counter.
3. **Footnote over-deletion destroys Greek prose** (dual-content verified). Guard: footnote detector is reversible, per-footnote citation-density gated, hybrid lines strip only the trailing citation tail, default flag-not-drop.
4. **ano-teleia missed by ASCII matching** — separator is U+0387 (006=983, ASCII '·'=0) in greek_phd but U+00B7 in Pergamos sections. Guard: match a codepoint class {U+0387,U+00B7} as equivalent separators, keep separate sub-counters, never NFC-fold.
5. **Inline-digit stripping corrupts real numbers / internal cross-refs** (βλ. Θεώρημα). Guard: count-only for in-text markers; never strip bare body digits; explicit internal-xref keep-list.
6. **Prerequisite noise on openarchives** — mojibake (002/011) breaks all regex; GFM tables are 38-75% of lines. Guard: mojibake quarantine + table handling run BEFORE reference logic.
7. **One-regime assumption under-recalls** — footnote / (Author,year) / numeric regimes are mutually exclusive per-doc (verified co-occurrence matrix). Guard: four independent in-text counters, no weighted aggregate; emit per-doc dominant_regime.

Unit tests pinned to this session's verified anchors. Land order: kallipos → pergamos → greek_phd → openarchives.
