## Tensions to resolve before the peak-LR sweep

1. **5.5e-5 peak vs practitioner-multimodal-cpt's ~1e-5 optimum.** The clearest cross-paper tension. That paper found the *rescaled* pretraining-reference LR (1e-5, batch-corrected from 1e-3) optimal and 1e-4 markedly more forgetting-prone — but it is OpenCLIP, b=512, full fine-tune, with no quantitative authority over Apertus-8B; the transferable principle is "derive CPT LR from the rescaled original pretraining peak and prefer it over larger." For Apertus, the analogous anchor is the pretraining peak 1.1e-4 and its final LR 1.1e-5. **5.5e-5 = 0.5×1.1e-4 is justified by Hagele's "half" prior** — which is itself only an empirical observation on 33M–360M models, not a rule. So the two LR-relevant papers pull in opposite directions (Hagele ≈0.5× peak; practitioner ≈ rescaled-reference, i.e. nearer the 1.1e-5 final-LR end). Both stress sweeping; treat 5.5e-5 as a sweep midpoint, not a derived value.

2. **Embedding LR: uniform vs differential is genuinely unsettled, and the doc's two strongest "uniform" citations don't support uniform.** `optimal-embedding-lr` is CONTRADICTED — it argues LR_emb = √d · LR_hidden (HIGHER, scaling with width not vocab). `ulmfit` / `llrd-bert-finetuning` point the opposite way (embeddings/lower layers LOWER). `allam-arabic-cpt` is the only clean uniform-LR + good-init data point (and never tested a differential new-row LR); `tokenization-bottleneck` is a single chemistry recipe, not "documented practice." Net: the literature does not converge on uniform, and the doc cannot lean on `optimal-embedding-lr` for it. If the sweep is to include an embedding-LR axis, decide explicitly between (a) uniform (ALLaM-style, demonstrated for vocab-extension CPT), (b) higher-emb √d (optimal-embedding-lr, from-scratch only), or (c) lower-emb (ULMFiT/LLRD, classifier-finetuning lineage) — they are mutually exclusive directions.

3. **β3=0.999 vs 0.9999 for a short CPT.** AdEMAMix App. C.1.5 supports β3=0.999 only for *low-iteration* runs (32k–64k steps), and Apertus's own post-training (SFT/QRPO) drops to β3=0.99 for fewer iterations. If the Greek CPT is short, the papers' own guidance favors a lower β3 than the pretraining 0.9999 — but note α=8 was only ever tuned at β3=0.9999 (no published α for 0.999), so changing β3 without re-checking α is unsupported. The doc's α=4 sits inside the general α∈[4,10] range but is not the reference α=8.

4. **β3=0.999 ≠ distribution-shift recommendation.** Don't justify a lowered β3 via "non-stationary / distribution-shift" attribution to C.1.5 — that regime has no experiment and no β3 value in the paper; the only valid lever there is iteration count.

5. **k=h=50 provenance.** Cite Apertus (CONFIRMED) for the k=h=50 value, not Goldfish (which never tests it and recommends k=3/4, h=13). If the sweep touches Goldfish strength, the in-paper-grounded range is small k with h=13.
