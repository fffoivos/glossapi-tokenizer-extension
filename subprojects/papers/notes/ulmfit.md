# Universal Language Model Fine-tuning for Text Classification (ULMFiT)

**Source:** arXiv:1801.06146  |  **Topic:** Embedding LR  |  `txt/ulmfit.txt`, `pdf/ulmfit.pdf`

**TL;DR.** Howard & Ruder (ACL 2018, arXiv:1801.06146) introduce ULMFiT, a transfer-learning recipe for NLP that pretrains an AWD-LSTM language model and fine-tunes it for classification using three techniques — discriminative (per-layer) learning rates, slanted triangular learning rates (STLR), and gradual unfreezing — to avoid catastrophic forgetting.

## Key load-bearing facts
- Discriminative fine-tuning (sec 3.2) = a DIFFERENT learning rate per layer (per-group). Parameters are split into per-layer groups {theta_1..theta_L} with per-layer LRs {eta_1..eta_L}; the SGD update uses eta_l for layer l. The paper explicitly calls this 'a novel fine-tuning method' (lines 278-284, 292-301).
- The empirical heuristic for setting per-layer LRs: choose eta_L for the LAST layer by tuning only the last layer, then set each lower layer to eta_{l-1} = eta_l / 2.6 (lines 319-322). Because each lower layer is the layer above divided by 2.6, embeddings and lower layers receive PROGRESSIVELY LOWER learning rates than the top layer. 2.6 is an empirical constant, not derived.
- Slanted triangular learning rates (STLR, sec 3.2) is a SEPARATE mechanism from discriminative LRs: it is a SCHEDULE OVER TIME (short linear warmup then long linear decay), not a per-layer scheme. Default hyperparameters: cut_frac=0.1, ratio=32, eta_max=0.01 (lines 309-310). 'Slanted' describes the time-shape of the triangle, NOT per-group differentiation.
- Gradual unfreezing (sec 3.3): unfreeze starting from the LAST layer (least general knowledge), fine-tune for one epoch, then unfreeze the next-lower layer, repeat. Motivated by Yosinski et al. 2014 (lower layers = more general features). Used together with Discr+STLR for classifier fine-tuning.
- Concrete recipe (sec 5): AWD-LSTM (Merity et al. 2017a), embedding size 400, 3 layers, 1150 hidden units, BPTT 70, Adam with beta1=0.7/beta2=0.99, batch 64, base LR 0.004 for LM fine-tune and 0.01 for classifier fine-tune; experiments used eta_L=0.01 for 'Discr' (lines 564-572, 818).
- Domain caveats for a CPT practitioner: this is a 2018 RNN/AWD-LSTM, sentence/document CLASSIFICATION study on small-to-mid English datasets (IMDb, TREC-6, AG, etc.), pre-Transformer. The per-layer 2.6 factor and STLR constants were tuned on the IMDb validation set (line 563). Ablation (Table 6/7) shows Discr and STLR help most on SMALL datasets (TREC-6), and cosine annealing is competitive with STLR on large data (lines 806-808, 836).
- Headline results: 18-24% error reduction vs SOTA on most of six classification datasets; matches from-scratch training with 100x less labeled data given 50k unlabeled examples (lines 78-89).

## Citation audit — what CURRENT_HYPERPARAMETERS.md cites this for

**Claim:** Origin of per-group / discriminative (slanted) learning rates.
**Verdict:** `PARTIAL`
**Evidence:** The paper DOES originate per-group/per-layer learning rates: 'we propose a novel fine-tuning method, discriminative fine-tuning. Instead of using the same learning rate for all layers ... discriminative fine-tuning allows us to tune each layer with different learning rates' and splits params into {theta_1..theta_L} with per-layer LRs (lines 278-297); listed as contribution #2 (lines 84-85). HOWEVER the parenthetical '(slanted)' conflates two DISTINCT mechanisms. 'Discriminative fine-tuning' = per-LAYER (per-group) LRs. 'Slanted triangular learning rates (STLR)' = a per-ITERATION schedule (warmup then decay), described separately in sec 3.2 (lines 323-356): 'STLR ... first linearly increases the learning rate and then linearly decays it'. STLR is not a per-group scheme.
**Correction:** Split the citation. Credit ULMFiT specifically for 'discriminative fine-tuning' = per-layer / per-group learning rates (contribution #2, sec 3.2). Do NOT label the per-group idea as 'slanted'; 'slanted triangular' is a separate time-schedule (warmup-then-decay) that ULMFiT also introduces. If the config doc's 'discriminative/slanted LR' is meant to denote a single mechanism, rename it to 'discriminative (per-group) learning rates' and treat STLR as the optional warmup-decay schedule. Also note this is an empirical heuristic for an AWD-LSTM classification setting, not a general theory.

**Claim:** The documented direction sets embeddings/lower layers to a LOWER LR, not higher.
**Verdict:** `CONFIRMED`
**Evidence:** Section 3.2 (lines 319-322): 'We empirically found it to work well to first choose the learning rate eta_L of the last layer by fine-tuning only the last layer and using eta_{l-1} = eta_l / 2.6 as the learning rate for lower layers.' Dividing each lower layer's LR by 2.6 relative to the layer above means embeddings/lower layers get strictly LOWER LRs than the top layer. Gradual unfreezing reinforces the same intuition: lower layers 'contain the least general knowledge'... 'starting from the last layer' (lines 394-396), i.e. lower/embedding layers are touched most cautiously.

## How we use it
Use ULMFiT as the canonical origin citation for DISCRIMINATIVE (per-layer/per-group) learning rates and for the direction 'lower/embedding layers get lower LR than top layers' — both are explicitly and correctly supported (sec 3.2, eta_{l-1}=eta_l/2.6; gradual unfreezing from last layer). For our Apertus-8B Greek CPT this directly motivates giving the newly-resized embedding rows / lower transformer blocks a smaller LR than upper layers when adapting to the extended Greek vocabulary, to limit catastrophic forgetting of the pretrained English/multilingual representations. Three caveats to carry into CURRENT_HYPERPARAMETERS.md: (1) the specific 2.6 factor and the 0.004/0.01 base LRs are AWD-LSTM + IMDb-classification numbers (2018, RNN, small data) and are NOT transferable constants to an 8B Transformer doing CPT — cite the mechanism and direction, not the magnitudes; (2) do not call the per-group scheme 'slanted' — 'slanted triangular' is a separate warmup-then-decay time schedule (eta_max=0.01, cut_frac=0.1, ratio=32) which, if we want a warmup analog, modern cosine/linear-warmup schedulers already cover (the paper itself notes cosine annealing is competitive with STLR on large data); (3) ULMFiT's ablations show the per-layer/STLR tricks help most on SMALL fine-tuning sets, so at full-corpus CPT scale the marginal benefit may be smaller than at low-data fine-tuning — treat per-group LRs as a forgetting-control lever, validated on our own Greek eval, rather than an assumed win.
