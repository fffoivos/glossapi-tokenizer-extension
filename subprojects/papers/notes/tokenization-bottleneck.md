# The Tokenization Bottleneck: How Vocabulary Extension Improves Chemistry Representation Learning in Pretrained Language Models (arXiv:2511.14365)

**Source:** arXiv:2511.14365  |  **Topic:** Embedding LR  |  `txt/tokenization-bottleneck.txt`, `pdf/tokenization-bottleneck.pdf`

**TL;DR.** A Thoughtworks NeurIPS-2025 workshop paper showing that extending Llama3-8B's vocabulary with ~17.8k chemistry (SMILES) and text tokens before continued pretraining beats standard CPT on downstream chemistry tasks, primarily by cutting SMILES token fertility (median 41 to 10 tokens/string).

## Key load-bearing facts
- Recipe is single-model vocabulary extension + CPT (not a dual-encoder/separate-tokenizer modality split): base = Llama3-8B; 17,795 new tokens added to the original 128k vocab (1,000 top OOV text tokens + 16,795 SMILES substructure tokens via SMILES-Pair-Encoding/BPE-style merges + special tokens like <SMILES>, <EOS>) (Sec 3.2, lines 167-192).
- New-token embedding initialization: 'the embeddings for these new tokens were initialized with the mean of all existing token embeddings in the original Llama 3 model' (Sec 3.3, lines 201-203). This is the 'good init' the project doc refers to. Note: mean-of-all-embeddings, a simple/cheap init, NOT a frequency-weighted or sub-token-average init.
- Learning rate schedule is a SINGLE global cosine decay with warmup applied to the whole model, not a separate/elevated LR for new embeddings: max LR 3e-4, min LR 3e-6, 200 warmup steps, cosine annealing (Sec 3.3 lines 203-205; Appendix B hyperparameter table lines 525-547). The paper never describes parameter-group-specific or differential LRs; the word 'uniform' does not appear.
- Other CPT hyperparameters (Appendix B): context window 8192, global batch size 16, Distributed Fused Adam, weight decay 0.1, betas (0.9, 0.95). Trained for a SINGLE epoch on the data blend on 32x H100 (4 nodes x 8) (Sec 3.4, lines 215-216, 529-547).
- Catastrophic forgetting is addressed via (a) 10B-token FineWeb data replay (61% of raw data, 50% of training-token weight) and (b) LR rewarming+redecaying, citing Ibrahim 2024 / Parmar 2024 / Gupta 2023 (Sec 3.1 lines 108-110; Sec 3.3 lines 199-200). Data blend weights: FineWeb 50%, USPTO 35%, L+M-24+SMolInstruct 10%, Chemistry Papers 5% of training tokens (Table 1, lines 116-148).
- Headline benefit is fertility reduction: base Llama3 tokenizer = median 41 tokens per SMILES string vs 10 with the extended tokenizer, shortening sequences and reducing fragmentation/compute (Sec on tokenizer fertility, lines 397-400). The vocab-extended model 'consistently outperformed the model that underwent standard CPT' on downstream chemistry tasks (lines 383-385).
- Scope caveat: this is a chemistry/SMILES domain-adaptation study on Llama3-8B, a workshop paper with a single base model and no LR/init ablation. It does not survey or compare vocabulary-expansion training recipes, so it is weak evidence for any general 'documented/standard practice' claim.

## Citation audit — what CURRENT_HYPERPARAMETERS.md cites this for

**Claim:** Documented practice is uniform LR + good init for vocabulary expansion.
**Verdict:** `PARTIAL`
**Evidence:** The paper describes its OWN single recipe, not a survey of 'documented practice.' It uses one global cosine LR schedule for the whole model (max 3e-4, min 3e-6, 200 warmup steps, cosine annealing; Sec 3.3 lines 203-205 + Appendix B lines 525-547) and initializes new-token embeddings as 'the mean of all existing token embeddings in the original Llama 3 model' (lines 201-203). So it IS consistent with 'one global LR + a sensible mean init.' BUT: (1) the paper never uses the word 'uniform,' never contrasts uniform-vs-differential LR, and never frames this as established/documented practice; (2) the word 'good' init is the doc's editorialization, the paper's init is specifically mean-of-ALL-embeddings, a cheap default, not a validated 'good' init, and there is no init ablation; (3) this is a single chemistry paper on one base model (Llama3-8B), so it cannot establish what 'documented practice' is across the literature.
**Correction:** Reframe to what the paper actually does, not as a statement of field-wide practice. Suggested: 'Kalamkar et al. 2025 (arXiv:2511.14365), extending Llama3-8B for chemistry, apply a single global cosine LR schedule to the whole model (max 3e-4, min 3e-6, 200 warmup steps) rather than a differential LR for new embeddings, and initialize new-token embeddings as the mean of all existing Llama 3 token embeddings. This is one data point, not a documented standard, and the paper runs no LR/init ablation.' If the doc wants to assert that uniform-LR + mean-init is common practice, cite a survey or multiple papers, this one paper does not support a generalization.

## How we use it
Use this as a concrete, recent worked example of the exact recipe shape this project plans (extend a pretrained model's vocabulary by merge-style BPE, then CPT) and as a sanity check on defaults, not as authority for 'standard practice.' Directly transferable data points: (a) new-token embedding init = mean of all existing embeddings is a viable cheap baseline for our Greek-token init; we should compare it against sub-token-average init since this paper does no init ablation. (b) A single global cosine LR (max 3e-4, min 3e-6, 200 warmup) with no differential LR for new embeddings worked here, useful as a starting point, but for Apertus-8B Greek extension we may still want to test an elevated/separate LR for the freshly-initialized Greek embeddings since this paper neither tests nor rules that out. (c) Catastrophic-forgetting mitigations to copy: heavy general-domain data replay (~50% of training tokens here = FineWeb) plus LR rewarming/redecaying (Ibrahim 2024). (d) The fertility-reduction framing (41 to 10 tokens/string) is the cleanest analogue to our Greek tokens-per-word goal and is the paper's strongest, best-supported result. Caveat for the config doc: do not cite this paper for a 'uniform LR + good init is THE documented practice' claim, downgrade that to PARTIAL and rewrite per the correction above, noting it is one chemistry/SMILES study on a single base model with no ablations.
